# 量化打分微服务 → 部署到腾讯云 CloudBase 云托管

同一套服务代码，改用**腾讯云 CloudBase 云托管（CloudBase Run）**部署。
对国内用户更友好：实名 + 支付宝/微信付款、访问快、有免费额度。
**全程网页操作，不用装任何命令行工具。**

## 一、CloudBase 适合吗？

适合。云托管专门跑 Docker 容器，我的服务代码不用改。
- **免费体验环境**：每月赠送资源点，够个人轻量使用（打分服务算力极小）
- **按量计费**：CPU 0.055元/核·小时、内存 0.032元/GiB·小时，闲时缩容到 0 就不计费
- **国内访问快**：数据源（东财）和你都在国内，延迟低

## 二、你要做的操作（约 15 分钟，全程网页点选）

### 1. 开通云开发环境
- 打开 https://console.cloud.google.com  ❌（这是谷歌，别去）
- 打开腾讯云开发控制台：**https://console.cloud.tencent.com/tcb**
- 微信/QQ 扫码登录 → 完成**实名认证**（身份证，几分钟）
- 「环境」→「新建环境」→ 选**按量计费**或**免费体验版**都行 → 记下**环境 ID**

### 2. 进入「云托管」新建服务
- 左侧菜单点「**云托管**」→「**新建服务**」
- 服务名称填：`quant-score`（只能小写字母/数字/短横线，字母开头）
- 网络、镜像仓库都用**默认配置** → 创建

### 3. 新建版本 = 上传代码 + 配置
点服务名 → 「**新建版本**」，按下面填：

| 配置项 | 填什么 |
|---|---|
| **上传方式** | 选「**本地代码**」，上传我给你的 `qlib-service.zip`（见下方"三"） |
| **监听端口** | `80` |
| **Dockerfile 名称** | `Dockerfile`（默认根目录，不用改） |
| **副本模式** | 低成本 |
| **副本个数** | 最小 `0`、最大 `2`（最小=0 才能闲时缩容不花钱） |
| **流量策略** | 开启 100% 流量 |
| **环境变量** | 加一条：Key=`API_KEY`，Value=**一串你自己定的密码**（比如 `qz` 加一串随机字符，记下来发我） |

> 环境变量 API_KEY 很重要：它是接口的钥匙，只有填了同一把钥匙的操盘台能调用你的服务，防止被别人盗刷。

点「**确定**」，等它构建+部署（首次约 3~5 分钟，能看到构建日志）。

### 4. 拿到服务地址
部署成功后，在服务详情页找到「**默认域名**」/「**公网访问地址**」，形如：
```
https://quant-score-xxxxx-xxxxxxxxxx.ap-shanghai.app.tcloudbase.com
```

### 5. 把两样发我
```
服务地址：https://quant-score-xxxxx...tcloudbase.com
API_KEY：你在第3步填的那串密码
```
我来把它接进操盘台（改 `api/ai.js`、在 Vercel 配环境变量、重新部署）。

## 三、要上传的代码包

上传给 CloudBase 的 `qlib-service.zip` 里应包含（**压缩包内直接是这些文件，不要多套一层文件夹**）：
- `app.py`
- `requirements.txt`
- `Dockerfile`
- `.dockerignore`

> 我已经帮你在 `qlib-service/` 目录打好了 `qlib-service.zip`，直接用它上传即可。

## 四、部署后自检（可选）
浏览器直接打开：`https://你的服务地址/health` → 看到 `{"ok":true,...}` 就成了。
（打分接口 `/score` 需要带密钥，浏览器直接开会返回 401，属正常。）

## 五、费用 & 下线
- **费用**：最小副本=0，闲时不计费；打分算力极小，正常个人用基本在免费额度内。
- **下线**：云托管控制台里把版本流量清零 / 删除服务即可，不留费用。

## 文件说明
| 文件 | 作用 |
|---|---|
| `app.py` | FastAPI 服务：`/score` 打分 + `/health` 健康检查 |
| `requirements.txt` | Python 依赖 |
| `Dockerfile` | 容器构建（端口自适应 80/8080） |
| `.dockerignore` | 构建忽略项 |
| `deploy.sh` | （Cloud Run 用的脚本，CloudBase 网页部署用不到，可忽略） |
