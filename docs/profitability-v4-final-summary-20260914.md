## 最优组合裁决

- **规则参数空间不存在稳定最优**：Task8 证明按 alpha 分位 top-K 追高是变相追动量，
  牛市赚熊市巨亏，三折平均为负。单折 +14% 是 regime 依赖，不可作为“最优解”。
- **模型预测净R 是正确的最优方向**：跨折验证证明「用 fold1+2 训练的模型预测净R」
  在完全未见的 fold3 上仍保持 RankIC 0.201 的单调分离（预测低档 -0.117 → 高档
  +0.164）。即“按模型分选股”比“按 alpha 分位选股”更能跨 regime。
- **因此最优组合 = v4 模型驱动的选股 + 保守风控（top2-3、单笔风险≤0.3%、
  持有≤5日、低相关去重）**，而非固定规则参数。alpha 作模型一维特征（路线2 本意）
  已被数据证实有效。

## 相对目标的诚实定位（目标：接近 10-20%/回撤≤10%/70%概率）

- **收益维度**：已能接近（保守配置牛市段 +9.5~14%），排序能力跨折稳定（RankIC 0.20）。
