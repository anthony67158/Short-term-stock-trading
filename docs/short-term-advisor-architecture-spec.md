# Spec: 极致短线游击作战闭环

## 核心命题

资金只停留在当前最强、赔率最优且能够执行的机会中；证据失效立即退出，
更强机会出现时重新配置。系统优化目标是费后正期望和回撤控制，不是交易频率。

## 关键约束

1. 新建仓遵守 A 股 T+1，当日无法卖出，因此入场门槛高于减仓门槛。
2. 持仓旧股可做 T，但必须区分可卖数量、当日买入锁定和 FIFO 成交归因。
3. 行情、资金和价格是硬事实；量化是概率先验；新闻是催化与风险证据；
   LLM 负责冲突解释和唯一动作。
4. 不恢复策略治理、版本晋级、影子建议或第二套决策链。
5. 所有交易继续由用户人工确认，系统不连接券商自动下单。

## 唯一主链

```text
战场状态
  -> 机会雷达
  -> 单股作战快照
  -> 军师唯一动作
  -> 确定性决策编译
  -> 人工执行
  -> 持仓与退出管理
  -> 事件复核
  -> 真实费后归因
  -> 置信与仓位校准
```

旧军师对市场、共振、板块、技术和资金对象的零散读取退出主链。快速生成、
深度研判、自动复核、仓位诊断和候选排序都使用同一事实语义。

## 一、战场状态

战场状态决定今天应该进攻、试错、防守还是空仓，不直接替军师选择股票。

固定输入：

- 当前交易时段与数据新鲜度。
- 指数强弱、涨跌家数、涨跌停、炸板率、连板高度和成交额。
- 活跃板块扩散、持续性和资金变化。
- 当前账户仓位、现金、行业集中度和当日回撤。

固定输出：

```js
{
  schemaVersion: 'battle-state.v1',
  phase: 'PREOPEN | OPENING | MORNING | NOON | AFTERNOON | CLOSE | OFF_HOURS',
  posture: 'ATTACK | PROBE | DEFEND | CASH',
  riskTone: 'RISK_ON | BALANCED | RISK_OFF | UNKNOWN',
  holdingWindow: 'INTRADAY | NEXT_SESSION | ONE_TO_FIVE_DAYS',
  reviewAfter: 'PRICE | FIVE_MINUTE_BAR | MATERIAL_EVENT | SESSION_BOUNDARY',
}
```

内部枚举不得直接展示给用户。

## 二、机会雷达

机会雷达负责回答“为什么是它，而不是其他股票”。

候选排序依据：

- 板块持续性和个股前排地位。
- 相对指数、板块和同类股票的强弱。
- 主力与小单资金关系。
- 流动性、换手、量比、盘中位置和拥挤风险。
- 量化方向、概率和目标区间。
- 催化新鲜度，以及催化出现后的真实价格反应。

只输出三类队列：

- 立即关注：已有优势，等待确定性触发。
- 回踩候选：强势但位置不合适。
- 淘汰：掉队、派发、流动性差或催化失效。

不得因“题材热门”自动给买入，不得因没有立即买点返回空名单。

## 三、单股作战快照

`short-horizon-tactical.v1` 是军师唯一单股输入合同，不是影子评分。

它必须包含：

- 市场姿态与交易时段。
- 板块状态和个股角色。
- 现价、相对强弱、流动性、拥挤度和盘中位置。
- 主力、小单、五日趋势及吸筹/派发/共识/背离关系。
- 量化概率和高把握状态。
- 新闻催化的新鲜度、方向和市场反应。
- 回踩、突破、止损、目标和合法价格锚点。
- 当前最重要的证据冲突。

## 四、军师唯一动作

未持仓动作：

- 立即买入
- 回调再买
- 小仓试错
- 观望

持仓动作：

- 加仓
- 持有
- 减仓
- 清仓
- 做 T

每条建议必须回答：

```js
{
  action: '唯一动作',
  shortHorizon: '盘中 | 下一交易时段 | 1-3个交易日 | 3-5个交易日',
  whyNow: '为什么现在值得行动或等待',
  edge: '相对其他机会的核心优势',
  crowdingRisk: '最可能导致短线失败的拥挤或兑现风险',
  actionPlan: '价格、手数和确认方式',
  exitTiming: '止损、止盈、移动保护和T+1处理',
  catalystWindow: '催化还剩多少时效',
  reviewTrigger: '下一次必须重评的事件',
  invalidation: '什么事实出现后原判断失效',
}
```

Prompt 不堆砌交易大师名词。快速和深度模式使用同一合同，深度模式只增加
反方核验和冲突分析，不能形成第二套结论。

## 五、确定性决策编译

代码只校验，不替军师决定方向：

- 行情和关键证据完整。
- T+1、可卖数量、涨跌停和交易单位。
- 现金、总仓、单票和行业集中度。
- 手续费、滑点和真实金额。
- 价格来自可核验证据且短期可达。
- 风险增加动作盈亏比至少 `1.8:1`。
- 小仓试错最多总资产 `5%`，必须人工确认。
- 硬止损和风险减少不得被软证据阻断。

## 六、单股作战生命周期

每只股票同一时间只允许一个阶段：

```text
发现
  -> 观察
  -> 待触发
  -> 已确认
  -> 人工执行
  -> 持仓管理
  -> 待退出
  -> 已结束
```

生命周期由当前建议、价格契约、执行计划和真实成交确定。旧建议、旧预警和
旧设备快照不得把已确认或已完成状态回滚。

## 七、资金轮动

仓位诊断升级为资金轮动决策，必须同时比较：

- 当前最弱持仓。
- 当前最强候选。
- 换仓需要支付的费用、滑点和 T+1 隔夜风险。
- 释放资金后的目标仓位。
- 不换仓时的机会成本。

模型只能从真实持仓和服务端候选池选择股票。每次最多给一个首要换仓动作，
其余作为条件候选，不制造大量并行指令。

## 八、退出管理

“快进快出”指证据响应快，不是固定第二天卖出。

退出顺序：

1. 硬止损或确定性风险。
2. 主力派发、板块退潮或个股掉队。
3. 目标位分批兑现。
4. 盈利后移动保护。
5. 到达建议窗口仍未兑现，按机会成本重新评估。

新仓当日触发止损但受 T+1 限制时，必须明确标记下一交易日优先退出。

## 九、事件驱动复核

行情轮询只运行确定性判断。以下事件才允许调用模型：

- 触及回踩、突破、止损或止盈价。
- 完整 5 分钟 K 线改变盘中结构。
- 主力与小单关系反转。
- 板块扩散转分化或个股前排资格变化。
- 量化高把握状态变化。
- 新公告、重大消息或账户状态变化。
- 交易时段边界。

无实质变化时复用原建议并生成核实回执。

## 十、真实成交学习

只学习完整、已核验的真实费后成交：

- 战场状态。
- 板块角色。
- 入场路径。
- 持有时长。
- 最大有利波动和最大不利波动。
- 盈利捕获率。
- 止损执行偏差。
- 滑点、费用和机会成本。

学习结果只调整置信表达和风险倍率，不能修改事实、绕过风控或直接生成方向。

## 用户界面

不新增策略卡或影子建议。用户第一屏只看到：

- 当前唯一动作。
- 作战阶段。
- 短线窗口。
- 核心优势和最大风险。
- 回踩/突破或止损/止盈路径。
- 下一复核事件。

完整证据、反方、量化、新闻和历史表现进入详情层。

## 性能预算

- 快速生成总预算不超过 75 秒。
- 深度生成总预算不超过 150 秒。
- 同一任务只允许一次主尝试。
- 端点故障切换和 JSON 整理只能发生在当前请求内。
- 无实质变化的自动复核不得调用模型。

## 成功标准

1. 生产主链不存在旧通用军师 Prompt 或双轨开关。
2. 所有军师建议包含唯一动作、作战阶段、短线窗口、退出和复核条件。
3. 一只股票不存在互相冲突的建议、预警和执行计划。
4. 仓位诊断能够输出一个可核验的首要资金轮动动作。
5. 非法价格、T+1、金额和仓位错误为零。
6. 无证据变化时建议不反复跳转。
7. 快速、深度、Harness、构建和双端生产验收全部通过。
8. 长期评价使用费后期望、盈亏效率、回撤、盈利捕获率和纪律执行率，
   不以交易次数或单纯胜率作为目标。

## 非目标

- 不承诺短期盈利。
- 不自动下单。
- 不引入新的策略治理体系。
