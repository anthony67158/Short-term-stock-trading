## V3/V4 联合排序消融

在不改 V3 概率和动作价值的前提下，将 V4 排序分位按
`0%/10%/.../100%` 权重混入 V3 排序。权重和阈值只看 2023-07-12 至
2025-02-07 选择段，2025-02-17 之后仍保持未见。

选择段所有权重均未获得正净R下界，不能据确认段表现反向挑权重。确认段中
部分混合权重能保持正收益，但都没有稳定优于纯 V3，故未形成可发布的联合模型。

## 既有 V4 候选复核

独立表现最好的既有 V4 为
`decision-review.1789422474.ensemble3`：252 日确认段年化 129 笔，
5bps `+5.83%`、10bps `+4.92%`、最大回撤 `8.88%`。
但净R下界为 `-0.01944R`，且同事件 V3 为 `+58.88%`、净R下界
`+0.04251R`，仍不构成相对提升。

## 本轮修正

1. V4 样本绑定 Alpha 快照 SHA-256，快照变化时自动失效旧缓存。
2. 多历史根按日期切点确定唯一归属，保留同区间严格冲突检测。
3. 未晋级 V4 仍执行同事件评估并输出改善证据，但继续阻断生产发布。
4. 离线评估支持发布后的 CatBoost JSON raw logit，与线上 sigmoid 语义一致。
5. 模型、校准和选择策略一起冻结，禁止选策后用选择段重拟合导致阈值漂移。
6. 无策略达到年化 80 笔时，回退优先保留最大真实覆盖，避免零交易候选获胜。

## 后续方向

继续坚持以下结构，不使用 Alpha158 Top50 硬过滤：

```text
多打法全市场召回
→ Alpha158 连续特征
→ V3/V4 联合机会排序
→ 回踩/突破触价
→ 10分钟复核
→ 账户组合与仓位仲裁
→ 唯一人工操作建议
→ 真实成交回流
```

下一轮重点是按动量、资金潜伏、回踩修复、事件催化拆分机会头，再以
`pFill × expectedNetRGivenFill` 做联合排序；退出继续单独比较持有、减仓和退出。
在 10bps 正收益、净R下界、跨年度盈利概率和回撤同时达标前，不提高现役风险仓位。
