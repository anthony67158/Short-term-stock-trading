# Alpha158 + V3 人工建议架构验收

日期：2026-09-14

## 结论

架构改造已完成，但 Alpha158 当前未获得生产权重。生产决策保持现役 V3，
Alpha158 以研究快照持续训练和留痕；只有未来时间外质量与账户收益门禁通过后，
才会自动获得不超过 25% 的连续排序权重。

系统没有新增券商自动下单。系统生成唯一操作建议，用户确认后自行操作并录入真实
成交；只有真实成交会改变现金、持仓、T+1 状态和训练归因。

## 已接通链路

```text
完整主板股票池
→ 动量/资金潜伏/反转/流动性/探索多路召回
→ Alpha158连续信号补充召回
→ V3动作价值与Alpha158联合排序
→ 回踩/突破价格触发
→ 10分钟V3复核
→ 账户现金、仓位、T+1、费用与尾损仲裁
→ 唯一MANUAL_ONLY人工建议
→ 用户记录真实成交
→ V3_ONLY/V3_ALPHA158分组归因
```

关键约束：

- 只处理沪深主板 `000/001/002/003/600/601/603/605`。
- Alpha158 不能删除原 V3 候选，不能覆盖价格、手数、止损和风险动作。
- Alpha158 缺失、过期、分布外或 Rank IC 不为正时权重为 0。
- 非 `DIRECT` V3 结果不能通过 Alpha158 升级为可执行。
- `USER_CONFIRMED` 只表示用户接受建议，不表示已成交。

## 账户影响

当前 Alpha158 权重为 0，联合排序逐项退回 V3，因此账户基准保持：

| 场景 | 收益率 | 最大回撤 | 平仓 | 平均资金利用率 |
|---|---:|---:|---:|---:|
| V3 / 5bps | +0.4229% | 4.1604% | 45 | 3.0063% |
| V3 / 10bps | -0.0866% | 4.3532% | 45 | 3.0136% |

对现有 157 个 V3 入选事件进行连续权重敏感性检查时，`0%-100%` Alpha 权重
均未改变账户结果，因为这些事件没有形成同日资金竞争。该结果不能证明 Alpha
有效，只说明现有低利用率样本不足以选择融合权重。

因此本轮不以 Alpha158 放大仓位，不宣称达到 10%-20% 收益或 70% 年度盈利
概率。后续由每日新增真实事件和成交继续积累可比较样本。

## 训练与发布

- 每日市场归档同时追加轻量主板日线不可变分片。
- 每日训练从 OSS 重建 Alpha158 面板和扩展时序 OOS 指标。
- OOS 指标用于质量门禁；当天分数由全部已成熟标签重新拟合后生成。
- 研究快照始终保存；只有质量和相对改善门禁通过时才切换 ACTIVE 清单。
- Alpha 任务失败采用局部降级，不阻断 V3 决策和 V3 每日训练。
