# R6：未调参年度(fold3)组合账户回放 — 真实结果

日期：2026-09-14
样本：`v4-training-samples.jsonl` 的 fold3（**未参与调参**，2025-05-09→2026-08-27，
320 信号日）。口径：净R组合回放，净R 已含费/滑点(5bps)，日线近似（非分钟触价）。
回放器：`scripts/replay-v4-portfolio.mjs`；验收门槛：`shared/profitabilityAcceptance.js`。

## 关键修复

初版回放器 `maxConcurrent` 远小于 `topK×horizon` 的自然持仓量，导致绝大多数
信号日建不了仓、仅 295/1600 笔且样本被扭曲（假 -37%）。修复：并发上限须匹配
周转量（topK×持有天数）。修复后 meanTradeNetR 与独立复算一致（+0.0626）。

## 诚实结论

- **正边际确认**：未调参年度上，alpha 选股组合收益为正（B 接近 10%），单笔均
  净R +0.06、胜率约28%（低胜率高赔率型），与 R4 分位排序证据一致。
- **未达标**：两配置最大回撤（60% / 21.8%）都 **> 门槛 10%**，滚动 12 月盈利
  概率与净R 95%下界不满足，`acceptance.passed=false`。
- **根因**：alpha 是**弱连续信号**，单独用作选股器（尤其追最高分）波动极大；
  必须作为 v4 模型的一维特征，与成交概率/盈利概率/尾部风险/低相关去重联合，
  由模型学习非线性组合来压回撤，而非规则式 top-K 追高。
- 这正是路线2 的设计初衷（alpha 作连续特征，不作硬过滤/选股器），R6 用真实
  数据证实了“只靠 alpha 分位选股不够”。
