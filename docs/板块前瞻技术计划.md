# 板块前瞻技术计划

> 依据：`docs/板块前瞻功能规格.md`
> 状态：Approved / In progress

## 一、架构

```text
Tushare历史回填 + 东方财富实时/历史
        ↓
sector_dataset.npz / 每日全量特征快照
        ↓
LightGBM双头(next/week) + V1确定性引擎
        ↓
冠军-挑战者、多指标护栏、错误样本加权
        ↓
OSS sectormodel/ 热更新
        ↓
FC /api/sector_forecast 全局任务
        ↓
豆包搜索 + 理论RAG + sector角色解释
        ↓
盘面研究 / 板块前瞻
```

## 二、组件

### 2.1 确定性核心

- `shared/sectorForecast.js`
  - 特征归一化。
  - 生命周期分类。
  - 拥挤/追高惩罚。
  - V1双周期评分。
  - LLM解释结果白名单合并。
  - 预测结算与统计。

### 2.2 主服务

- `api/_sector_forecast_data.js`
  - 全量概念、历史资金/K线、成分股、市场环境采集。
  - 外部数据解析与超时。
- `api/_sector_forecast_store.js`
  - OSS最新、历史、设置、任务、结算。
- `api/_sector_forecast_llm.js`
  - 豆包合并检索、理论RAG、`sector`角色解释。
- `api/sector_forecast.js`
  - GET latest/history/settings。
  - POST generate/save_settings/run_due/settle。
  - 鉴权、幂等、single-flight。

### 2.3 量化服务

- `qlib-service/sector_factors.py`
  - 板块特征与双标签。
- `qlib-service/build_sector_dataset.py`
  - Tushare历史回填和每日增量。
- `qlib-service/sector_model.py`
  - 双LightGBM模型加载、OSS热更新、推理。
- `qlib-service/train_sector_model.py`
  - walk-forward冠军-挑战者。
  - 近期样本加权。
  - 预测错误持久重放。
- `qlib-service/app.py`
  - 新增 `/sector-predict`，不改 `/predict`。

### 2.4 UI

- `src/components/SectorForecast.jsx`
  - 次日/一周分段控件。
  - 前瞻榜、生命周期、动作等级、数据截至时间。
  - 行内展开解释和真实成分股。
  - 历史回测折叠区。
  - 自动设置弹层。
- `src/components/ResearchTab.jsx`
  - 放在概念走势之前。

## 三、模型

### 3.1 特征

- 资金：1/3/5/10日净额、净占比、连续性、斜率、加速度。
- 价格：1/3/5/10/20日收益、相对收益、位置、回撤、波动。
- 结构：上涨家数、资金流入家数、涨停扩散、龙头/中军。
- 流动性：成交额、换手稳定性。
- 市场：风险状态、全市场量能与涨跌扩散。
- 拥挤：当日涨幅分位、涨停占比、价格/资金背离。

### 3.2 标签

- Next：T+1收盘横截面前20%。
- Week：T+1开盘至T+5收盘超额收益横截面前20%，并记录最大回撤。

### 3.3 错样本

- 每次结算把高置信错误写入 `sectormodel/hard_errors.json`。
- 下一轮训练按置信度和时间衰减施加 2~3 倍权重。
- 盲测窗绝不参与错样本标记。

### 3.4 晋级

- 同一独立盲测窗比较冠军和挑战者：
  - AUC。
  - LogLoss。
  - NDCG@5。
  - Top5 precision。
- 双头均不得显著退化，至少一头有真实提升。

## 四、自动任务

- FC Timer每5分钟调用 `run_due`。
- 运行时设置决定是否在 15:10 / 08:50 执行。
- 时间范围：北京时间 `HH:mm`，收盘任务限制 15:05~23:59，盘前任务限制 06:00~09:25。
- 关闭开关后Timer仍可空调用，但禁止生成和付费。
- 同交易日同场次最多成功一次，手动refresh除外。
