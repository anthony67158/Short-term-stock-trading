# ADR-008: 人工执行交易系统的产品与训练目标

## 状态

Accepted

## 日期

2026-09-15

## 决策权威性

本文是产品定位、模型训练、回测、发布和验收的上位目标合同。后续方案若把固定
收益、固定交易次数或单笔胜率作为模型优化目标，或与本文的目标分层冲突，以本文
为准。账户安全、真实交易约束及既有数据兼容要求不受影响。

## 背景

系统面向 A 股短线人工执行场景：系统给出唯一、明确、可复核的操作建议，用户
自行下单并录入真实成交。系统不自动连接券商下单。

此前的目标同时包含滚动十二个月盈利概率、年度收益、最大回撤、压力收益、单笔
净 R 下界和年交易数量。这些数字分别属于长期产品效果、生产资格、风险约束和
容量诊断，却曾被混合用于模型选策，容易产生以下偏差：

1. 为达到交易数量而补入负期望机会；
2. 用提高仓位或降低成本假设制造名义收益；
3. 把股票涨跌预测当成可执行交易价值；
4. 用合成持仓、固定期限和理想成交代替真实操作过程；
5. 在数据合同不完整时继续增加模型维度和复杂度；
6. 把账户年度盈利概率误解为单笔胜率或模型分类准确率。

当前证据已经显示这种偏差：

- V3 的 191 日账户回放在 5bps 下为 `+0.4229%`，10bps 下为
  `-0.0866%`，说明成本安全垫不足。
- V4 虽达到年化 `126.66` 笔，但净 R 下界为负、最大回撤超过 `10%`，
  说明覆盖增加不等于盈利改善。
- 当前 V4 历史训练数据缺少 review VWAP、初始 V3 价值评分和板块状态，
  176 维中有 53 维恒定。
- 当前持仓研究模型约 `91.9%` 输出退出，训练样本又缺少真实 T+1 可卖比例和
  生产可建仓分布，不能代表真实持仓管理。

## 产品定义

系统的产品目标是：

> 在人工执行条件下，持续输出少而明确、费后正期望、风险可解释的唯一操作建议，
> 并把策略判断、市场结果和人工执行偏差分别记录和评估。

系统不是收益承诺产品，也不是交易次数生成器。市场不存在满足条件的机会时，
`WAIT` 或保持现金是正确决策，不是系统失效。

用户每次应得到一个完整答案：

- 当前唯一动作：等待、买入、持有、加仓、减仓或退出；
- 可执行价格或价格区间、触发条件和有效期；
- 精确手数和操作后的目标持仓；
- 硬止损、止盈保护和失效条件；
- 费后价值、主要下行情景和仍缺少的证据；
- 未成交时明确作废，不按理论价格记账。

## 目标分层

### 1. 产品长期验证指标

以下指标用于检验产品长期是否创造价值，不是收益承诺，也不直接作为单个模型的
训练标签：

- 滚动 12 个月账户盈利概率目标 `>=70%`；
- 年度收益中位数目标 `10%-20%`；
- 最大回撤目标 `<=8%-10%`；
- 建议质量与人工执行偏差可分离归因。

这些指标必须来自包含真实费用、滑点、未成交、部分成交、人工延迟、T+1 和资金
占用的账户级时间外回放或真实成交，不得由分类准确率、IC 或单笔胜率外推。

### 2. 生产资格与发布门槛

生产新增风险决策至少满足：

- 相对现金方案的费后增量期望为正；
- 10bps 压力情景收益为正；
- 费后净 R 的 95% 下界目标 `>=0.02R`；
- 账户级最大回撤不超过授权上限；
- 数据、特征、标签、价格、费用和风险合同完整；
- 在独立时间外数据上没有未来信息泄漏；
- 新挑战者在同事件、同成本、同风险条件下优于当前冠军。

在首个合格基线尚未建立时，可以保留诊断模型或挑战者，但不得通过提高仓位、
放宽费用、补入负期望交易或复用确认集取得生产资格。

### 3. 风险约束

账户风险是约束，不是收益调节旋钮。模型和 LLM 均不得自动提高单笔风险、开放
风险、集中度、总仓位或杠杆。T+1、可卖量、现金占用、整手、涨跌停、费用、
滑点、硬止损和真实成交记账始终优先。

### 4. 训练目标

训练优化的是可执行动作的风险调整后费后增量价值：

```text
expected action utility
= pFill * E[netR | fill]
 - uncertainty reserve
 - tail-loss cost
 - capital-occupation cost
 - turnover and execution cost
 - portfolio concentration cost
```

未成交不能按理论买入价产生收益；负期望不能通过增加交易数量或仓位变为正期望。

### 5. 容量与诊断指标

年化 `120-160` 笔只用于判断正期望策略能否形成足够收益容量，不是交易配额或
选策优先级。模型排序、Alpha 分位、召回率、资金利用率和信号数量同样只是诊断：

- 有正期望但覆盖不足，优化召回与执行；
- 覆盖充足但期望为负，减少交易并修复候选、标签或退出；
- 没有合法正期望机会，保持现金。

## 决策链路

系统按以下顺序工作：

```text
多打法全市场召回
-> Alpha158 等信息作为连续特征
-> 现价、回踩、突破路径估值
-> 触价后的短窗口复核
-> 账户组合与目标仓位仲裁
-> 唯一人工操作建议
-> 真实成交和未成交记录
-> 策略结果与执行偏差分别回流
```

召回层可以追求覆盖，但没有交易授权；价值层决定是否值得交易；账户层决定能否
交易以及交易多少。任何排序模型都只能在已满足绝对正期望的合法候选中决定优先级。

## 训练架构

不使用单一涨跌分类器代替完整决策，也不把“176 维”本身视为产品进步。训练拆为：

1. **机会召回**：宽召回多种打法，不使用 Alpha TopK 或旧公式提前淘汰合法股票。
2. **成交模型**：预测路径在有效期内的成交概率、成交比例和成交时间。
3. **条件收益模型**：只对真实或可核验反事实成交学习费后收益分布。
4. **尾部风险模型**：估计 Q10、跳空和路径失效风险。
5. **横截面排序**：仅在同一真实决策批次的合法正期望候选中排序。
6. **组合仲裁**：考虑现金、开放风险、相关性、集中度和机会成本。
7. **持仓与退出**：使用真实持仓年龄、T+1 批次、可卖比例及 1/3/5 日动作价值，
   独立比较持有、加仓、减仓和退出。
8. **执行归因**：分别评估系统建议、实际成交价格、成交比例和人工延迟。

新增维度只有在决策时点可获得、覆盖率合格、非恒定且通过时间外消融后才能进入
生产合同。无法因果回填的历史字段应从生产特征合同删除或明确失败关闭，不能用
`UNKNOWN`、普通零值或全缺失掩码伪装为有效信息。

## 验证原则

1. 使用按时间前推的 purged walk-forward；训练、校准、选择和最终确认严格分离。
2. 最终确认集只使用一次，失败后不得继续在该时间段调参。
3. 回测必须复现召回、触价、复核、成交、持仓、退出和账户资金占用的完整链路。
4. 同时报告建议数、订单数、真实成交数和完成交易数，交易覆盖只统计真实成交。
5. 费用至少包含佣金最低收费、印花税、过户费和条件滑点。
6. 采用连续块重采样评估净 R 下界，不能把重叠事件当作独立样本。
7. 比较挑战者时固定数据、风险、成本、阈值和确认窗，禁止只挑有利口径。
8. 报告绝对结果优先于相对提升；两个负期望模型中较好的一个仍不具备生产资格。

## 禁止事项

- 禁止把 `120-160` 笔设为必须完成的训练或发布目标。
- 禁止把 `70%` 解读为单笔胜率、分类准确率或短窗口正收益比例。
- 禁止用提高仓位、杠杆、集中度或降低滑点假设证明盈利改善。
- 禁止为补足 TopK 强制加入负期望候选。
- 禁止仅凭模型维度、AUC、RankIC、IC 或回测收益宣称产品目标达成。
- 禁止把理论触价当作真实成交，把未成交建议计入盈利。
- 禁止让 LLM 覆盖动作、价格、手数、账户风险或费后价值。
- 禁止在关键训练字段缺失时继续训练可部署模型。

## 后续工作优先级

后续工程按以下顺序推进：

```text
完整且可信的数据与回测合同
-> 至少一个打法/路径形成绝对正期望
-> 真实成交与执行摩擦建模
-> 严格时间外验证
-> 概率校准与联合排序
-> 组合去相关和资金利用
-> 真实持仓分布上的退出模型
```

当前首先补齐 V4 历史 review VWAP、严格时间外的初始 V3 评分和可因果恢复的板块
状态，再重建训练集。未通过数据覆盖审计前，不继续以增加模型复杂度作为主要工作。

- 延续 [ADR-004](./ADR-004-v3-selective-model-release.md) 的冠军挑战者、原子发布和
  可回滚原则。
- 延续 [ADR-006](./ADR-006-trading-value-v2.md) 的条件化收益、价格绑定、时间用途
  分离和基线风险档。
- 对既有文档中“固定交易笔数优先”“单项相对改善即可发布”或“用固定收益目标直接
  驱动训练”的表述，本文予以取代。
- 本文不表示当前 V3、V4 或持仓模型已经达到上述生产资格。

## 后果

- 交易数量可能下降，但每笔交易必须先证明绝对费后价值。
- 市场机会不足时，系统会更频繁地输出等待或保持现金。
- 训练工作将优先投入数据合同、标签和执行真实性，而不是继续堆叠模型维度。
- 产品汇报必须明确区分长期目标、当前实测、生产门槛和诊断指标。
- 系统仍只输出唯一建议，用户仍只需人工执行并录入真实成交。
