# ADR-004: V3 组成部分选择性发布

## 状态

Accepted

## 日期

2026-09-11

## 背景

V3 每日训练此前会在模型文件和数值合同有效后直接替换当前 DIRECT 基准。
这种方式能快速使用最新数据，但无法保证新版本相对现役版本有增益，也无法在
只有部分模型头改善时保留其它稳定部分。

V3 生产组合包含三个固定种子的 LightGBM 动作价值头和 CatBoost 排序头。
模型头之间存在依赖，不能只看单项指标就直接替换；任何部分晋级后都必须重新
评估混合组合的费后收益、尾部风险、校准和推理性能。

## 决策

当前 `usagePolicy=DIRECT` 模型是每日训练的唯一冠军。新训练模型只作为挑战者，
不会在评估前覆盖生产清单。

模型分成五个可独立晋级单元：

1. `fillProbability`：成交概率模型与校准参数。
2. `winProbability`：成交后盈利概率模型与校准参数。
3. `payoff`：胜单 R 和亏单 R 两个幅度模型。
4. `tailRisk`：Q10 模型与校准偏移。
5. `ranking`：CatBoost 排序模型、排序校准和混合权重。

每个单元先单独替换到冠军包中，并在同一独立盲测集上与冠军比较。只有达到
对应最小改善且没有单项硬退化的单元，才进入组合穷举。所有可行子集随后再次
执行完整推理和整体效果验证，最终只选择一个通过全部风险阈值的最佳组合。

整体发布硬阈值：

- Top5 费后净 R 相对冠军最多下降 `0.01R`。
- Top5 净 R 的 95% 下置信界必须大于 `0`，且最多下降 `0.02R`。
- Top5 正净 R 命中率最多下降 `2` 个百分点。
- 最大回撤增幅不得超过冠军的 `5%` 或绝对 `0.05R`，取较宽者。
- 正期望覆盖率不得低于 `2%`，且最多下降 `5` 个百分点。
- 两个概率头的 Brier 分数最多恶化 `0.01`。
- 净 R 平均绝对误差最多恶化 `5%`。
- Q10 覆盖率不得低于 `85%`，且最多下降 `2` 个百分点。
- 千条推理耗时不得同时增加超过 `25%` 和 `1ms`。

没有单元改善、没有组合通过、冠军包无法验证或发布写入失败时，生产
`manifest.json` 保持不变。通过验证的发布包先写不可变模型文件和
`release-history/<version>.json`，最后原子更新生产清单。

量化汇报只展示 V3 每日训练与发布管理，记录训练批次、冠军、挑战者、选中
版本、各单元结论、整体指标、阈值、阻断原因和部署状态。个股辅助模型与板块
模型继续独立训练，但不再写入该汇报入口。

## 备选与取舍

不采用每日整包无条件替换，因为它无法证明相对现役版本的收益。

不采用只看单模型头指标直接替换，因为校准、动作价值和排序存在耦合，局部
改善可能导致整体净期望、回撤或延迟恶化。

不采用人工逐次发布。自动化选择和原子清单切换减少操作遗漏，同时保留不可变
审计记录和版本级回滚能力。

## 后果与回滚

每日训练仍会生成新挑战者，但生产版本可能连续多日不变。选择性发布产生的
模型包可能同时包含不同训练批次的模型头，其来源记录在元数据
`releaseManagement` 和 OSS 发布决策中。

回滚时把 `opportunitymodel/manifest.json` 恢复为任一历史发布版本即可；
不得删除历史模型文件或发布决策。
