# ADR-001: 日报采用场次化决策模板、分级证据包与云端调度

## 状态

Accepted

## 日期

2026-08-23

## 背景

旧日报把一份结果拆成三路并行 LLM JSON 请求。任一路返回空对象、截断
JSON 或缺少 `overview` / `strategy` 时，整份日报只返回“核心内容不完整”。
同时，公告、媒体新闻与搜索摘要只以标题字符串进入模型，来源、日期、链接
和证据等级丢失，军师无法追溯结论。

用户还需要在浏览器关闭后按自定义时间自动生成盘前、午间和收盘日报。
`daily-report.v2` 解决了生成失败和证据追溯问题，但三个场次仍共用接近的
“市场 + 持仓公告 + 板块”结构，与个股军师重复，无法回答盘前预案、午间
纠偏和盘后复盘三个不同问题。

## 决策

1. 日报升级为 `daily-report.v3`，三个场次使用互斥的固定模板：
   - 盘前 `morning-plan`：隔夜传导、政策/产业与机构线索、今日板块池、
     今日个股池、确定性关键价位和开盘执行顺序。
   - 盘中 `noon-correction`：上午累计成交、资金前五、异动个股、早报逐项
     验证，以及下午加/减/观望条件。
   - 盘后 `evening-review`：全天量能、收盘主线、龙虎榜、北向实际成交、
     早报复盘、次日预案与海外观察。
2. 证据优先级固定为：
   - 公司公告、监管与政策原文。
   - 行情、板块资金和高权威媒体。
   - 豆包/SearXNG 搜索摘要，仅作待核验线索。
3. 搜索计划按场次变化。盘前检索隔夜传导、政策产业催化和机构观点；午间只
   补盘中突发；盘后检索收盘复盘和下一交易日海外事件。普通权威度自媒体结果
   不进入日报证据包。
4. 硬数据与观点物理分层。板块池复用确定性板块前瞻；个股池从板块成分股产生，
   买入区、止损和压力位由日线技术指标计算。LLM 单次生成本场观点和动作，
   不能改变候选池、关键价位、资金、龙虎榜或北向数据。
5. 午报和晚报读取同账号同日盘前报告，按实时板块涨跌和主力资金逐项标记
   `confirmed` / `invalidated` / `pending`。盘前报告缺失时必须明确显示无法
   复盘，不得倒推早报观点。
6. 2024 年 8 月后的北向口径只展示成交总额、沪股通/深股通成交额、成交笔数
   和十大成交股。净买额固定为 `null` / “未披露”，不得把接口中的空值转换为
   `0` 或据此判断流入流出。
7. 每条软信息保留来源、链接和发布时间；LLM 输出继续校验证据编号与数字
   可追溯性。模型失败时由硬数据生成规则版并标记 `degraded`。
8. 自动计划保存在账号 `settings["dailyReport.schedule"]`。独立 FC Timer
   每五分钟扫描一次，到期后以异步 Worker 生成；同一日期和场次使用租约、
   完成记录和最多三次尝试防重。
9. 受账号鉴权保护的 `/api/daily_report_schedule`：
   - `POST {"action":"get"}` 读取设置与运行状态。
   - `POST {"action":"save","settings":...}` 保存三个场次的开关和北京时间。

## 外部来源选择

豆包搜索 Global 版作为网页检索主源。官方接口支持 API Key 鉴权、默认
5 QPS、单次最多 20 条结果和每月免费额度：

https://www.volcengine.com/docs/87772/2548026?lang=zh

不新增 Google Custom Search JSON API。Google 官方文档说明该接口已停止
接纳新客户，并将在 2027-01-01 停止服务：

https://developers.google.cn/custom-search/v1/overview

SearXNG 作为可选补充入口接入。只有同时设置 `SEARXNG_ENABLED=true` 与
`SEARXNG_BASE_URL=https://...` 才调用；地址需通过公网 HTTPS/SSRF 校验，
结果只保留监管、交易所和指定财经媒体域名。系统不自动发现或依赖公共实例。
实例需在 `settings.yml` 显式启用 JSON 输出：

https://github.com/searxng/searxng/blob/master/docs/dev/search_api.rst

## 后果

- 日报结论可由 `E##` 追溯到来源、日期和链接。
- 三份日报不再重复个股军师的持仓公告摘要。
- 午报和晚报能明确显示早报判断的验证、证伪或待确认状态。
- 盘前候选关键价位来自确定性指标，模型不能覆盖。
- 搜索摘要无法单独推动买入或加仓，且外部文本继续按不可信输入处理。
- 自动任务不依赖浏览器常驻，不占用军师 `advisor` 角色端点。
- 每个启用场次每天最多生成一次；失败在时间窗内最多尝试三次。
- 自动生成会产生 `daily` 角色模型和豆包搜索调用费用，因此默认总开关关闭。
