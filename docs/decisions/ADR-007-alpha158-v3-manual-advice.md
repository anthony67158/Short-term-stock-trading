# ADR-007: Alpha158 作为连续信号接入 V3 人工建议链

## Status

Accepted

## Date

2026-09-14

## Context

主板 Alpha158 样本外回放的整体 IC 为 `0.020619`，Rank IC 为
`0.004197`，Top50/Drop5 在 10 万元账户中收益为 `-13.7907%`。将
Alpha158 Top50 与 V3 候选做硬交集后，只剩 4 笔平仓，收益为
`-0.5909%`。这证明 Alpha158 在当前样本中不能独立决策，也不能作为
排他性召回门槛。

当前 V3 在 5bps 下收益为 `+0.4229%`，但平均资金利用率只有 `3.0063%`，
10bps 下收益降至 `-0.0866%`。系统需要增加有效机会覆盖，同时保留 V3
对成交概率、条件收益和尾部风险的控制。

用户只需要系统给出建议并自行操作，不需要券商自动下单。系统仍需依据用户
记录的真实成交更新资金、持仓、T+1 和训练标签。

## Decision

生产链固定为：

`多打法全市场召回 → Alpha158连续信号 → V3联合机会排序 → 回踩/突破触价
→ 10分钟V3复核 → 账户组合与仓位仲裁 → 唯一人工建议 → 真实成交回流`

### 1. Alpha158 不是硬门槛

- Alpha158 输出独立的原始分、截面分位、模型版本、数据时点和近期 Rank IC。
- 联合排序把 Alpha158 分位作为连续输入；禁止使用 TopN 交集删除 V3 候选。
- Alpha158 缺失、过期、分布外、Rank IC 不为正或未通过冠军挑战者门禁时，
  权重固定为 0，系统完全退回现役 V3 排序。
- Alpha158 不能改变价格合同、成交概率、手数、止损、目标或账户风险上限。

### 2. 联合排序必须时间外训练

- 历史 Alpha158 分数必须来自扩展时序样本外预测，不能用全量拟合结果回填。
- Alpha158 与 V3 的联合权重只在选择段确定，确认段只验证冻结权重一次。
- 发布时比较现役 V3 与联合挑战者在同一新增留出集上的费后机会净 R、下界、
  回撤、覆盖率和账户收益。
- 没有可验证改善时保持 V3，不能为了提高资金利用率降低正期望门槛。

### 3. 唯一人工建议

系统对同一股票和决策版本只发布一个当前动作：

- `BUY/ADD`：价格区间、整数手数、最大金额、有效期、止损、目标和失效条件。
- `HOLD`：持有边界和下一次重评条件。
- `REDUCE/EXIT`：可卖手数、执行价格条件和 T+1 限制。
- `WATCH`：只保留回踩或突破触发条件，不冒充可执行委托。

`USER_CONFIRMED` 仅表示用户接受建议，不表示已成交。只有用户录入的真实成交
才能推进 `PARTIALLY_RECORDED/COMPLETED`、改变账户和形成真实学习标签。

### 4. 收益门禁

研究目标不是发布承诺。联合挑战者只有同时满足以下条件才可替换生产：

- 确认段费后净 R 的 95% 下界大于 0。
- 10 万元账户在 5bps 和 10bps 下均为正收益并优于现役 V3。
- 收益改善不是单纯来自更高风险或更低覆盖率。
- 最大回撤、尾部损失、费用占比和单一板块集中度不恶化。
- 至少覆盖预先冻结的多市场状态分段；样本不足时结论为“未证实”。

年度收益 10%-20%和滚动年度盈利概率 70%是研究目标，不是单次回测发布条件
或未来收益保证。

## Consequences

- 当前 Alpha158 模型保持研究态，不因本 ADR 自动进入生产。
- 生产排序需要保留 V3 原始分、Alpha158 原始分、实际融合权重和联合分，
  便于归因与回放。
- 自动化只负责生成、失效和跟踪建议；不新增券商报单能力。
- 每笔真实成交必须关联 `decisionId`、模型版本和执行偏差，未成交建议不能
  伪造成已执行收益。
