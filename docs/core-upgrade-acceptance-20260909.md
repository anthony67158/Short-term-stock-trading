# 核心决策升级与验收

日期：2026-09-09。目标为减少错误执行与信息拼接，提高短线决策的可执行性；
不是通过增加交易频率、降低确认阈值或许诺收益来证明优化。

## 核心改造

| 问题 | 实施 |
| --- | --- |
| 模型正文、页面数量、执行计划不一致 | 服务端核定动作、价格、数量、金额后统一回写；前端不再独立估算手数 |
| 小额交易毛赔率好、费用后不划算 | 费用和滑点后净盈亏比至少1.8；现金、预留、单票、行业和账户风险共同限制手数 |
| 触及目标概率冒充盈利胜率 | 显式目标触及标签不再用于证明止损前交易正期望；缺失概率说明具体缺项 |
| 不同措辞漏过硬风险 | 用结构化流动性、位置、市场状态与加仓资格判断，不匹配解释文案 |
| 持仓退出随模型改口 | 不得下移账本止损掩盖破位；深破与第五交易日退出遵守T+1 |
| 老计划长期留在可执行区 | 实时指令不跨午休，隔夜预案按交易日历；过期、已完成及最新风险阻断的买入不再提示执行 |
| 同一计划反复触价、重复复核 | 双观察路径共享计划级幂等键；观察窗口结束后一次模型终局 |
| 结果未保存就通知、账本核验失败仍发布 | 先保存再推送；无法核验最新交易事实则失败并保留上一版 |
| 模拟成交污染效果学习 | 模拟账户/记录排除出真实收益学习 |
| 刷新后先展示缓存，用户修改被延迟GET覆盖 | 记录本地修改版本；恢复期间发生修改只合并云端运行态，保留本地账本并用原版本规则保存 |
| 已完成计划移除后被旧完成版本恢复 | 两个完成版本按更新时间选择，保留较新的移除标记与原成交记录 |

关键实现：`shared/decisionPlan.js`、`tradeExpectancy.js`、`exitManagement.js`、
`api/_advice_wakeup.js`、`cron_advice.js`、`src/planStore.js`。

## 实际模型

使用生产“测试账号”、固定模拟资金及持仓；没有修改个人生产账本。
行情为实际股票报价，生成不是模型替身。断点续验读取同一任务ID，没有重新生成同题。

| 股票 | 路径 | 耗时 | 结果 |
| --- | --- | --- | --- |
| 000001 平安银行 | 浏览器点击持仓深度生成 | 129.865秒 | 同一任务仅领取1次；输出回执完整；决策/价格/监控合同、OSS保存、条件提醒与刷新恢复通过 |
| 688981 中芯国际 | 浏览器点击快速生成 | 27.368秒 | 同一任务仅领取1次；输出回执完整；决策/价格合同、OSS保存与刷新恢复通过 |
| 000001 平安银行 | 独立review角色、实际行情 | 23.688秒 | 模型返回、退出动作、可卖数量与决策合同通过 |

深度生成输出回执：`finishReason=stop`、正文2274字符、推理8165字符、
缺失字段0；快速生成正文1223字符、缺失字段0。以上为单次任务耗时，
不代表延迟分位数或可用性统计。没有为了验收强行制造买入；
平安银行复核为API实跑，不冒充线上Timer全链路。

证据：`harness-artifacts/production-combat/report.json`、`deep-result.json`、
`quick-result.json`、`review-result.json`及页面截图。

## 本地回放

真实比亚迪收盘报价86.57元作为价格尺度，路径、资金和模型结果为明确标记的本地模拟。
真实业务函数负责报价判断、排队、60秒观察、结果核定、通知、人工计划及记账。
浏览器只连接本机，禁止访问生产API。

通过：重复报价只提交一次、观察期间零模型调用、终局只调用一次模型、
持久化后通知、重复通知去重、手动确认与成交、费后现金、T+1、刷新恢复及复盘。
模型调用数1、观察窗口60000ms、触价提交数1。

证据：`harness-artifacts/combat-replay/report.json`、`persisted-terminal.json`及截图。
运行：`PLAYWRIGHT_MODULE=<本机Playwright路径> node scripts/verify-combat-replay.mjs`。

刷新恢复竞态另有真实浏览器最小复现：删除后100ms、1200ms返回旧快照，
修复前均恢复了已删内容；修复后本地与保存结果均保持删除，各保存1次。
证据：`harness-artifacts/account-restore/report.json`，
回归脚本：`scripts/verify-account-restore.mjs`。真实云端出现过8-10秒的大快照保存耗时，
本次修复防止编辑丢失，不宣称该网络/快照性能瓶颈已经消失。

## 尚未证明

- FC Timer离线接力、浏览器系统级通知送达、锁屏/后台体验。
- 自定义域名的测试账号完整工作台：已有浏览器恢复个人账号后立即关闭，
  未使用该会话执行生成或交易；独立会话仍需要设备授权。
- 没有穷举全站所有页面、市场状态、连续压力场景与上游故障。
- 目标触及概率保护仍有旧数据兼容路径；未完成新的胜率模型训练和全口径迁移。
- 时间退出规则在生成/复核执行，尚未证明每只持仓都能被Timer实时独立发现。
- 没有足够真实收益样本证明利润提高，也不承诺保证盈利或零缺陷。

因此，本轮核心修复和已列链路通过，不等于“全站全场景验收完成”。
生产盘中实际报价触发已补验；后续只需在具备有效浏览器推送订阅的测试设备上
补验系统通知送达与离线Timer接力。
