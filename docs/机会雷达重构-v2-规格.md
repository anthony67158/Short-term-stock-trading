# 机会雷达重构 V2 规格

> 状态：Implemented
> 日期：2026-09-03
> 目标：把混合信息面板重构为全站唯一、可验证的选股入口

## 目标

机会雷达是全站唯一选股入口，只回答两个问题：

1. 交易时段内，今天有哪些股票可以立即买入、等待回踩/突破，或进入尾盘反转观察。
2. 收盘后，哪些股票值得加入下一交易日关注计划。

成功标准：

- 顶层只保留“盘中机会”和“次日关注计划”两个页签。
- 切换页签后，数据来源、操作按钮、状态摘要和候选分组均明显不同。
- 不再展示“方向观察”股票；没有完整个股价格合同的板块成分股不进入候选列表。
- 板块前瞻只作为公式候选的方向校验、排序依据和标签，不单独制造股票候选。
- “选股准确”使用 Top-K 精度、触发后可成交率、扣费后期望 R 和最大回撤共同衡量，不承诺单一胜率。

## 选股能力架构

采用“规则负责召回、模型负责排序、风险层决定能否操作”的三层结构：

```text
全市场完整读取
  -> 硬性可交易过滤
  -> 多策略候选召回
  -> 市场/板块条件交叉验证
  -> pFill × pWinGivenFill × expectedNetR 排序
  -> 组合去重与风险预算
  -> 人工执行
  -> 全候选结果结算与再训练
```

### 候选策略族

| 策略族 | 用途 | 生产状态 |
| --- | --- | --- |
| 盘中回踩承接 | 趋势内回踩 VWAP/均线后恢复承接 | 保留并加强 |
| 盘中资金先行 | 价格温和、量能放大、主力与小单结构确认 | 保留并加强 |
| 5–30 分钟订单失衡延续 | 捕捉短时资金推动，必须绑定流动性与时段 | 新增影子策略 |
| 60–120 分钟过热反转 | 识别追高衰竭，只做降级/回避信号 | 新增风险过滤 |
| 收盘趋势回踩 | 趋势向上、缩量回踩、次日确认 | 保留并加强 |
| 收盘波动收敛突破 | BOLL/ATR 收敛后等待次日放量突破 | 保留并加强 |
| 尾盘反转 | 现有 14 条固定公式与 T+1/T+3 纪律 | 原样保留 |
| 板块/同业相对强度 | 验证个股是否处在有效方向和扩散阶段 | 只作条件变量 |
| 公告与事件催化 | 给候选增加或降低置信度 | 不单独生成买点 |

研究依据：

- 2024 年同行评议研究显示，经典同分钟日内动量在中国 A 股中的证据较弱，因此不直接照搬海外日内动量公式。
- 2025 年中国市场高频研究显示，订单失衡对 5–30 分钟收益呈正向预测，但 60–120 分钟可能反转，因此必须拆成不同持有窗口。
- 2025 年中国市场研究支持技术指标与流动性条件结合优于单独使用任一类信号，但结果仍需在本项目数据上重新走样本外验证。
- Qlib 官方中国市场基准显示，不同模型和特征集表现差异明显；LightGBM、DoubleEnsemble 等只能作为候选模型，不能把公开基准收益直接视为本系统收益。
- 价格涨停研究显示，频繁触及涨停可能对应更低的未来横截面收益，涨停次数和临近涨停拥挤应作为风险惩罚而非追涨加分。

详细证据见：

- `docs/research/opportunity-radar-stock-selection.md`
- `docs/research/opportunity-radar-selection-strategies-20260903.md`

### 统一排序目标

规则固定分只用于解释与初始召回，不得冒充概率。候选排序使用独立机会模型：

```text
P(触发)
× P(触发后可成交)
× P(成交后净盈利 | 已成交)
× 预期净 R
- 下行尾部风险
- 拥挤与同板块重复暴露
```

模型输出必须继续保持 `shadowOnly`，直到同时满足：

- 时间净化的 walk-forward 结果稳定优于简单基线。
- `pFill` 与 `pWinGivenFill` 均完成独立校准。
- `Precision@3 / Precision@5`、NDCG、Brier、LogLoss 达标。
- 扣除佣金、印花税、过户费和滑点后，期望 R 为正。
- 至少覆盖 1000 个成熟候选、300 个触发样本和 60 个完整成交样本。
- 不同市场状态与流动性桶没有出现不可接受的集中失效。

### 硬过滤

以下条件在任何模型评分之前执行：

- 停牌、退市整理、风险警示范围和不支持板块。
- 价格或交易日不新鲜。
- 涨跌停或价格笼子导致无法合理成交。
- 成交额、换手率或历史样本不足。
- 入场、止损、目标、时效或至少 `1.8:1` 盈亏比不完整。
- 账户现金、T+1、单股仓位、同板块暴露或总风险预算不允许。

LLM 只解释候选与证据，不参与全市场召回、数值排名或硬风控放行。

## 信息架构

### 盘中机会

按固定顺序显示三个区段：

1. **可立即买入**
   - 仅包含 `READY` 且价格合同完整的盘中公式候选。
   - 展示买入价、最大仓位、止损、止盈和有效时段。

2. **今日提前布局**
   - 仅包含 `WAIT_TRIGGER` 且价格合同完整的盘中公式候选。
   - 明确还差哪个价格、量能或资金条件，不得写成可以买入。

3. **尾盘反转**
   - 14:50 自动运行正式扫描，14:52 只做失败重试。
   - 提供独立“手动扫描”按钮；手动结果不覆盖正式结果。
   - 严格命中与接近公式分开展示。
   - 接近公式只保留观察价值，不得进入可执行买入状态。
   - 14:50 前显示下一次自动运行时间；任务运行时展示真实进度。

盘中主刷新按钮只更新板块盘中快照和盘中公式，不隐式启动尾盘扫描。

### 次日关注计划

- 仅在收盘后允许用户手动生成。
- 数据来源为当日收盘板块快照和当日收盘公式。
- 不包含尾盘反转结果；尾盘反转始终属于“盘中机会”。
- 交易时段内显示“收盘后可生成”，不复用昨日结果冒充今日次日计划。
- 收盘后生成时展示真实任务进度，完成后自动读取新结果。
- 生成结果必须包含入场条件、最大仓位、止损、止盈和时间退出。

## 日期与新鲜度

- 盘中机会只接受当前交易日的盘中公式和尾盘结果。
- 次日关注计划在收盘后只接受当前交易日的收盘公式。
- 次日盘前可继续查看上一交易日收盘后生成的计划。
- 当日开盘后，上一交易日计划退出“次日关注计划”，不得继续显示为新计划。
- 昨日价格不得显示为当前价；历史结果只允许进入复盘，不进入当前候选。

## 交互

- 顶部主按钮随页签变化：
  - 盘中机会：`扫描盘中机会`
  - 次日关注计划：`生成次日关注`
- 尾盘区独立按钮：
  - 空闲：`手动扫描`
  - 运行中：显示真实阶段和进度
  - 14:50 前：同时展示“14:50 自动扫描”
- 页面在 14:50、15:05 等关键结果时点自动重新读取；后台标签页继续执行。
- 页面关闭、组件卸载或设备离线后停止前端轮询。

## 数据与状态

候选只保留：

- `READY`：当前满足执行条件。
- `WAIT_TRIGGER`：价格合同完整，但仍待价格、量能或资金确认。
- `AVOID`：公式候选存在，但当前不允许买入。

`SECTOR_WATCH` 仅保留为历史兼容枚举，不进入 V2 用户界面。

来源状态增加：

- `scheduled`：尚未到运行时间。
- `running`：任务正在运行。
- `pending`：已到运行时间，等待任务结果。
- `fresh / stale / missing / failed`：沿用现有语义。

## 边界

必须：

- 保留全市场完整读取与完整性校验。
- 保留原尾盘公式和量化 36 维口径。
- 结果为空时明确显示真实结论。
- 前端改动同时部署 Vercel 与阿里云 FC。
- 后端或定时器改动部署阿里云 FC。

禁止：

- 板块方向单独生成个股候选。
- 接近公式包装成可以买入。
- 交易时段复用昨日结果冒充今日次日计划。
- 自动修改自选、持仓、现金或交易流水。
- 使用生产账号执行有副作用验收。

## 验收标准

1. 顶层仅有两个页签。
2. 盘中页明确分为“可立即买入 / 今日提前布局 / 尾盘反转”。
3. 页面不再出现“方向观察”列表或 `方向可看` 状态。
4. 尾盘严格结果为 0 时仍显示独立区段和接近公式结果。
5. 次日计划在收盘前不展示昨日候选，收盘后可手动生成。
6. 15:05 收盘公式定时器停止自动生成，保留手动入口。
7. 所有候选均来自公式并带完整价格合同，或明确标记为接近公式。
8. 320、768、1024、1440 宽度无溢出。
9. 全量测试、Harness、构建与线上只读验收通过。

## 已采用假设

- “收盘后的手动运行”表示取消收盘公式自动定时生成，仅保留用户手动生成。
- “今日提前布局”不是板块成分股列表，而是已有完整价格合同、尚待触发的盘中公式候选。
- “尾盘反转”包括严格命中和接近公式，但两者必须明确分层。
