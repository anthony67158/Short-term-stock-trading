# V3 决策接入

## 范围

本次只切换持仓、自选和到价复核的决策链，并简化交易卡片。训练、回测、
模型晋级与 `/predict` 因子口径不在本次修改范围。

`api/_v3_decision.js` 读取权威账户、行情、日线、资金与板块，调用现有
`QUANT_URL/opportunity-score`。特征保持 `opportunity-score-feature.v3`。
现价、回踩、突破分别评分，避免按股票代码索引的响应串用价格合同。
三条路径必须使用同一模型版本。

## 决策权

- `buy_advice`、`hold_advice`、`review` 在读取 LLM 配置之前进入 V3 服务。
- `cron_advice` 的任务执行调用同一服务，继续使用已有租约、交易指纹、
  单股增量保存和发布前账户核验，不依赖 LLM 配置或成功返回。
- V3 提供成交概率、成交后费后盈利概率、净 R 与尾损。现有确定性价格引擎
  提供价格路径，账户编译器核定手数。LLM 不参与动作、价格、数量选择。
- 持仓使用现价剩余路径价值管理持有或退出，覆盖标记为
  `REMAINING_PRICE_PATH`。这不是新训练的加仓/持有/减仓/退出四动作模型，
  当前不会虚构加仓概率。
- 已核定动作直接产生同源提醒，不再经过 LLM 二次确认。回踩、突破观察价
  仍走到价观察和 V3 复评；旧版或过期系统预警不再触发。

## 失效与风控

- 保留模型服务的 `productionEligible`、`shadowOnly`、分布外和数值校验。
  模型尚未就绪时明确展示未就绪，不回退手写概率或旧军师建议。
- 新增风险必须有完整关键证据、正费后价值和账户容量。未成交买入预留现金、
  单票/行业仓位、账户开放风险与模型尾损参与手数计算。
- 账本止损独立于模型与资金数据成功；T+1 约束今日可卖手数。
- 普通弱市只调整风险预算，不使用旧市场档位直接否决。
- 已完成、取消、过期或偏离参考价的指令不再作为卡片可执行主操作。
- 本轮没有改变真实持仓、费用、现金、成交和执行归因的数据结构。

## 界面

卡片按“当前动作与手数 → 何时操作 → 参考价 → 风险边界”展示。
持仓、自选的主操作与摘要共用 `v3DecisionPresentation`。
普通收藏先纳入作战；执行时记录真实成交；等待时查看跟踪条件。
详情提供更新决策、查看依据和盯盘预警，不再提供快速/深度两种决策入口。
“查看依据”展示模型输出和资金事实，不代表调用了独立 LLM 解释服务。

## 验证与回滚

- `test/v3-decision.test.js`：三路径、价格概率同源、账户预留、尾损、
  过时报价、缺失资金、止损、零 LLM 调用和预警版本。
- `test/v3-decision-presentation.test.js`：动作与按钮、未就绪、过期、
  已结束指令、参考价偏移、T+1 与止损。
- `scripts/verify-v3-workbench.mjs`：本地假数据六状态、四断点、成交与详情返回。
- `scripts/verify-production-combat.mjs --online`：只允许测试账号，真实 API
  评估、OSS 保存、刷新与独立浏览器恢复、模拟成交；结束恢复固定夹具。
- 按项目规则同时发布 Vercel 和 FC。不迁移账本；发生数据一致性或主链故障时，
  部署发布前代码版本恢复服务，保留账户真实数据，不回写旧账户快照。
