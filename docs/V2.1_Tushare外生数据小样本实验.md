# V2.1 Tushare 外生数据小样本实验

## 结论

Tushare 有可用于 V2.1 的独立信息，但不能把“接口存在”直接等同于“适合历史盘中训练”：

| 数据 | 官方接口 | 历史盘中实验价值 | 因果口径 |
|---|---|---|---|
| 个股历史分钟 | `stk_mins` | 已是 V2.1 基础数据 | 只用 `asOf` 以前数据 |
| 交易所指数分钟 | `rt_idx_min` | 仅当日实时，不能直接回填历史训练集 | 适合从现在开始前向积累 |
| 行业指数 | `ths_index` / `ths_daily` | 只有目录和日线，没有标准历史行业分钟接口 | 盘中只能使用上一交易日值 |
| 个股资金流 | `moneyflow` | 有独立订单流信息，优先小试 | 盘后更新，严格滞后一个交易日 |
| 行业资金流 | `moneyflow_ind_ths` / `moneyflow_ind_dc` | 可用于行业环境，但需要行业映射 | 盘后更新，严格滞后一个交易日 |
| 大盘资金流 | `moneyflow_mkt_dc` | 可补充全市场风险偏好 | 盘后更新，严格滞后一个交易日 |
| 开盘集合竞价 | `stk_auction` | 2025 年起，适合盘中预测 | 9:26 后可作为当日已知信息 |
| 收盘集合竞价 | `stk_auction_c` | 只能用于标签诊断 | 盘中严禁作为输入 |
| 实时逐笔 | `realtime_tick` | 只覆盖当日且为爬虫接口 | 不进入首轮历史 A/B |
| 历史五档盘口 | 无等价标准历史接口 | 当前不可直接回测 | 需要独立 Level-2 数据源 |

2026-08-12 当前账号实测：

| 接口 | 结果 |
|---|---|
| `stk_mins` 个股 5 分钟 | 可用 |
| `stk_mins` + 指数代码 | 返回空数据 |
| `rt_idx_min` | 无权限 |
| `moneyflow` | 可用 |
| `ths_index` / `ths_daily` | 可用 |
| `moneyflow_ind_ths` / `moneyflow_ind_dc` | 可用 |
| `moneyflow_mkt_dc` | 可用 |
| `stk_auction` | 无权限 |
| `stk_auction_c` | 调用失败 |

## 首轮范围

- 股票：最多 24 只。
- 日期：最近 90 个有样本交易日。
- API 调用：`1 + 24 × 3 = 73` 次。
- 模型：LightGBM 序列汇总基准。
- 对照：同一股票、同一样本、同一训练/校准/净化留出日期。
- 预测头：`next30m` 与 `sessionClose` 独立比较。
- 不修改生产 V2/V2.1 路由，不写 EAS 环境变量。

首轮新增 9 个特征：

```text
上一交易日自由流通换手率
上一交易日量比
上一交易日主力净流入 / 流通市值
上一交易日大单和超大单不平衡度
上一交易日大盘主力净流入占比
上一交易日大盘超大单净流入占比
当日开盘竞价缺口
当日开盘竞价换手率
当日开盘竞价量比
```

## 晋级规则

小样本只决定是否值得扩大研究，不决定上线：

```text
next30m 平衡准确率提升 >= 0.005
sessionClose 平衡准确率提升 >= 0.005
双头平均提升 >= 0.01
```

任一预测头不改善即停止扩大。即使通过小样本，后续全量候选仍须满足原生产硬门槛：

```text
next30m balanced accuracy >= 0.58
sessionClose balanced accuracy >= 0.58
```

## 首轮真实结果

首轮使用已归档的 LightGBM 留出预测做二阶段增量验证，避免为了小试解压约 32GB 全量训练集或启动 GPU：

```text
股票数：24
交易日：90
样本数：40,848
训练：2026-03-19 ~ 2026-05-29
校准：2026-06-03 ~ 2026-06-29
最终测试：2026-07-02 ~ 2026-07-29
净化日期：2026-06-01、06-02、06-30、07-01
```

账号没有开盘竞价权限，因此实际可用覆盖率为：

```text
上一交易日个股资金流：100%
上一交易日大盘资金流：100%
当日开盘竞价：0%
```

校准期在“个股资金流”“大盘资金流”“个股+大盘资金流”三个候选中选择了个股资金流组合。最终测试结果：

| 预测头 | 同结构基础组 | 加入个股资金流 | 增量 |
|---|---:|---:|---:|
| `next30m` | 0.4276 | 0.4253 | -0.0023 |
| `sessionClose` | 0.5133 | 0.5057 | -0.0076 |

结论：**拒绝扩大训练，不上线**。上一交易日资金流对同一交易日内所有 5 分钟样本是低频、重复的上下文，首轮没有提供稳定的双头增量。下一轮若继续，应优先：

1. 使用行业成分映射，把行业日线和行业资金流做成相对强弱，而不是继续堆单股日频资金流。
2. 从现在开始前向积累指数分钟线；历史指数分钟需要另找合规数据源。
3. 只有取得集合竞价或 Level-2 历史权限后，再测试盘口微观结构。

## 运行

先通过环境变量临时注入 Token，不打印、不写入代码：

```bash
export TUSHARE_TOKEN='...'
```

只读权限探针：

```bash
python3 qlib-service/tushare_v21_research.py \
  --trade-date 20260811
```

采集小样本缓存：

```bash
python3 qlib-service/collect_tushare_v21_pilot.py \
  --data intraday_v21_dual_head.npz \
  --out v21_tushare_pilot.json \
  --max-codes 24 \
  --max-dates 90
```

运行 A/B：

```bash
python3 qlib-service/run_intraday_v21_exogenous_pilot.py \
  --data intraday_v21_dual_head.npz \
  --cache v21_tushare_pilot.json \
  --out v21_tushare_pilot_metrics.json \
  --max-codes 24 \
  --max-dates 90
```

轻量留出增量验证：

```bash
python3 qlib-service/evaluate_intraday_v21_exogenous_pilot.py \
  --predictions v21_lgbm_holdout_predictions.npz \
  --cache v21_tushare_pilot.json \
  --out v21_tushare_pilot_metrics.json \
  --max-codes 24 \
  --max-dates 90
```
