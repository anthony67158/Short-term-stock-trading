# 主板复核模型 V3 离线验收

日期：2026-09-14

## 范围

- 股票池仅包含沪深主板：`000/001/002/003/600/601/603/605`。
- 排除创业板、科创板和北交所。
- 历史范围为 191 个信号交易日，前 48 日用于初始训练，后 143 日使用三个扩展时间折生成样本外选择。
- 入场只接受完整分钟线；持有期分钟缺失时使用不可用于入场的日线 OHLC 补全退出路径。

## 数据与模型

- 主板事件：77,466。
- 有效触发事件：40,202。
- 真实成交条件收益样本：17,346。
- 未成交机会按 `0R` 进入机会排序评估，但不进入条件收益训练。
- 模型版本：`decision-review.1789360354.ensemble3`。
- 结构：三种子 CatBoost 成交、条件胜率、条件净 R、Q10 和机会横截面排序头。
- 最优冻结策略：`DECOMPOSED + RANKER`，`pWin >= 0.50`，条件净 R 不低于 `-0.10R`，Q10 不低于 `-1R`。

三折扩展回放产生 157 个样本外候选，其中 80 个真实成交。账户使用 T+1、整数手、真实费用、现金冻结和持仓上限。

研究档在排除最后一个漂移折后为 `+1.7058%`，10bps 为 `+1.0554%`。风险放大没有把收益提升到 10%-20%，不能称为模型能力提升。

## 裁决

- 模型级净 R 下界门槛通过，可作为当前最优复核模型发布。
- 10%-20%收益和 70%盈利概率未达到，继续作为优化目标。
- 不启用 `ABSOLUTE_CAP`，不把账户回放结果表述为稳定盈利证明。
- 保留完整回滚版本和 60 个交易日前向记录要求。
