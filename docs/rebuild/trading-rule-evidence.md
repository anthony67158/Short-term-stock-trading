# 首批交易内核的规则证据

核验日：2026-09-15。代码：`backend/src/platform_app/kernel/trading.py`。
当前范围仅为 A 股竞价限价申报数量与普通买入批次 T+1，不代表已支持完整执行计划。
规则仅对2026-07-06至核验日接受查询；历史回放及后续日期须补充版本证据。

2026-09-16（上海实际运行日期）再次读取上述上交所现行有效状态、深交所PDF
及北交所正文，数量规则未变，核验区间延至2026-09-16。深交所3.3.11、
北交所3.3.10均为A股0.01元申报单位。人工账本计划仅使用数量/价格单位与
资金预留，不声称完成盘中交易资格、价格笼子、涨跌停或账户权限核验。

| [北交所2026交易规则](https://www.bse.cn/jygl_list/200028217.html) | 3.3.8买卖100股起；3.3.9上限100万；3.1.4买入当日不得卖出 |
| [北交所技术系统指南2026](https://www.bse.cn/uploads/6/file/public/202604/20260424154914_mdlsmp6dt4.pdf) | 买卖基本变动单位1股，不足100股余股一次卖出 |

不把北交所暂缓的盘后交易自动启用，不推断所有板块涨跌停比例。
价格笼子、权限、交易日历、证券状态与历史生效关系另行实现，数量规则通过不等于可执行。

成交事实不调用申报数量验证器，真实部分成交可不足最小申报数量。
T+1使用上海成交日期；批次只在后续日期供卖出消耗。这是账本投影约束，
不是把每个自然日视为交易日，计划和撮合仍需核验交易日历。
FIFO成本分配以分为单位，最终卖出消耗剩余全部成本，避免累计舍入损失。
实际费用来自交割单；估算费用及券商订单级最低佣金尚未实现。

三份公告均发表于2025-12-22。缺少精确发布时间，点时可用时间保守设为
次日上海零点；更早asOf查询返回未知。调休周末仍休市。跨入尚未核验的年度
时下一交易日为null，并保留缺失原因。仅代表已公告年度安排，不声称覆盖
临时停市、个股停牌、盘中交易时段或实时开市状态。
