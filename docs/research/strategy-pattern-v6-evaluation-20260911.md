# 五策略形态 V6 评估

评估日期：2026-09-11

## 复验更正

**下文首轮模型对比不再作为有效的独立样本外证据。**

后续真实行情验收发现，集成训练曾把最终留出集用于概率校准与混合权重选择。
同一数据再次进入发布评估会高估效果。已修复为训练、校准、最终留出三段严格
隔离，同时修复首日亏损漏计最大回撤的问题。原始首轮结果保留仅供事故追溯。

按修复后的因果形态与价格路径重放，得到 42,497 条成熟路径、21,546 条成交
路径，覆盖 60 个信号日。新挑战者
`opportunity-score.20260911T143615Z.ensemble3` 的训练截止为 07-23，
校准截止为 08-12，最终留出从 08-20 开始，两个边界各隔离 5 个交易日。

严格留出评估结果：

| 指标 | 结果 |
|---|---:|
| Top5 平均费后净R | -0.152733R |
| Top5 净R下界 | -0.555578R |
| 最大回撤 | 2.1766R |
| 盈利概率 AUC | 0.500549 |
| 盈利概率 Brier | 0.253125 |
| Q10 覆盖率 | 82.9664% |
| 正期望候选占比 | 23.578% |

发布结果仍为 `KEEP_CURRENT`，但原因已不只是覆盖率不足：当前挑战者缺乏
可靠区分能力，且实际留出收益与尾部校准不合格。不能因为预测正期望数量增加
就认定策略有效。首轮 19.31% 是事后“至少一条路径盈利”的增量样本计数，
不是前向盈利提升，也不是全市场机会召回率；不得据此宣称交易效果已提升。

## 首轮数据（仅追溯）

- OSS 不可变行情归档：127 个交易日；
- 因形态计算需要 60 日前置窗口，可完整评估 60 个信号日；
- 三时点、三路径因果回放：43,126 条成熟路径；
- 完整成交路径：22,761 条；
- 形态历史覆盖率：99.78%。

## 首轮召回统计（不作门禁证明）

五策略形态通道在原 96 只深查池之外新增 2,818 个独立候选，占全部独立候选
15.18%。其中 1,029 个候选至少存在一条正净R路径，相对原召回池的正样本数量
增加 19.31%。首轮曾将此视为通过“正样本召回至少提升 5%”门槛；
该结论已撤回，因为缺少全市场机会分母，且使用了事后路径结果。

按主要形态统计：

| 形态 | 新增候选 | 至少一条正净R路径 |
|---|---:|---:|
| 量价齐升 | 1,809 | 696 |
| 缩量回踩 | 312 | 104 |
| 低波动趋势 | 450 | 161 |
| 长下影反击 | 128 | 32 |
| 平台整理突破 | 119 | 36 |

新增候选同时带来较多负样本，因此只能交给动作价值模型排序，不能把公式命中
直接升级为交易动作。

## 首轮模型结果（留出集已污染）

挑战者：`opportunity-score.20260911T124224Z.ensemble3`

冠军：`opportunity-score.20260910T200644Z.ensemble3`

同一末段留出集上，挑战者相对冠军：

- 盈利概率 AUC：`0.5067 -> 0.5621`；
- 盈利概率 Brier：`0.2191 -> 0.2161`；
- Top5 平均净R：`0.0126R -> 0.4204R`；
- Top5 净R下界：`-0.2955R -> 0.0440R`；
- 推理耗时：`23.35 -> 23.99 ms/1000`。

但完整门禁仍拒绝发布：

- 三折 walk-forward 中存在负净R窗口；
- 正期望覆盖率只有 `0.2378%`，低于 `2%`；
- Q10 覆盖率下降超过 2 个百分点。

## 结论

发布决策为 `KEEP_CURRENT`。五策略代码、历史快照和 v6 合同可以部署为
`RESEARCH`，但不得启用 `STRATEGY_PATTERN_POLICY=ACTIVE`，现役 V5
生产模型和交易动作保持不变。
