# Implementation Plan: 交易价值模型与可验证执行架构 V2

状态：APPROVED（2026-09-14），实施中。
依据：[交易价值模型与可验证执行架构 V2 规格](./trading-engine-profitability-v2-spec.md)。

## Overview

本计划先修复模型输入、标签、时间隔离和发布验证，使历史结果与生产执行可同源复算；再训练成交、条件收益和尾部风险模型；最后在相同风险档下评估账户收益，并仅在`BASELINE`先通过后评估`ELEVATED_RESEARCH`。公告与ETF研究不进入第一轮生产切换。

不承诺通过架构改造必然盈利。任何挑战者未通过费后收益、同风险超额收益和风险门禁时，生产保持失败关闭或现役合格版本。

## Architecture Decisions

1. **唯一决策核心**：继续复用`decisionStateContract`、`actionValueArbiter`、`targetPositionModel`和执行账本；回测通过适配器调用这些模块，不复制决策公式。
2. **价格合同先于模型**：复核特征包含入场价、止损价、风险分母、费用基准和缺失掩码；预测回显合同哈希，服务端不匹配即拒绝。
3. **标签条件化**：完整事件账本训练成交头；已成交且可核验样本训练条件收益和尾部风险头。未成交不伪造收益标签。
4. **真实标签区间隔离**：所有训练分区按`labelStartAt`和`labelEndAt`清除跨界样本，不使用固定5日假设。
5. **选择与确认分离**：训练/校准/候选选择/最终确认四段时间用途互斥；最终确认段只验证冻结候选一次。
6. **风险档版本化**：`BASELINE`、`ELEVATED_RESEARCH`和`ABSOLUTE_CAP`由共享合同定义。负期望模型不能通过提高风险档晋级。
7. **原子发布**：特征、价格、标签、退出、风险和模型元数据组成兼容版本包；任一不匹配即失败关闭。
8. **收益来源隔离**：公告因子只有通过点时证据门禁后才能加入；ETF继续作为独立研究基准。

## Dependency Graph

```text
ADR与共享版本合同
  ├─ 复核特征V2 + 价格合同哈希
  │    ├─ 服务端评分请求/响应绑定
  │    └─ Python模型加载/推理校验
  ├─ 完整事件账本 + 条件化标签
  │    ├─ 实际标签区间purge
  │    └─ 成交/收益/尾损训练
  ├─ 四段时间隔离
  │    └─ 候选选择 + 一次性最终确认
  └─ 风险档共享合同
       └─ 同源账户回放
            └─ 风险收益曲线与发布报告
                 └─ 测试账号验收 / 原子部署
```

## Implementation Phases

### Phase 1: 可相信的数据与合同

- 发布ADR-006，冻结V2语义、风险档和一次性确认规则。
- 建立复核输入V2、显式缺失掩码和价格合同哈希。
- 服务端在模型评分前构造最终价格合同，并校验返回哈希。
- 模型注册表只加载完整兼容包，旧V1继续失败关闭。

**Checkpoint A**

- JS/Python金样对同一输入产生相同特征顺序与合同哈希。
- 缺失VWAP、量、初评分时不会被编码成普通0值。
- 评分结果无法绑定到不同入场/止损合同。
- 当前生产模型因V2不兼容保持不可用于新增风险。

### Phase 2: 标签与时间隔离

- 将完整触发事件与已成交条件收益样本分离。
- 保存真实`labelStartAt`、`labelEndAt`、成交状态和退出合同版本。
- 按真实结果区间实现训练/校准/选择/确认分区及purge。
- 增加截断未来、后续修正不回写和同事件路径分组测试。

**Checkpoint B**

- 未成交事件只进入成交标签，不产生伪收益标签。
- 任一标签结束时间跨越边界的样本均不进入较早分区。
- 延长历史数据不会改变过去的特征、分区和标签。

### Phase 3: 交易价值模型 V2

- 训练成交概率头。
- 训练成交条件下的胜率、正负幅度、直接净R和逐样本Q10头。
- 增加特征支持度与缺失分布检测。
- 输出明确区分`pFill`、`pWinGivenFill`、`expectedNetRGivenFill`和成交前机会价值。

**Checkpoint C**

- 不再固定`pFill=1`或`outOfDistribution=false`。
- 校准与风险指标使用独立时间段。
- 直接净R与分解模型作为预先登记消融，不在最终确认集择优。

### Phase 4: 选择、确认与风险档

- 候选成员组合只在选择段决定。
- 冻结候选在最终确认段只运行一次。
- 风险档进入共享配置与报告；生产默认仍为`BASELINE`。
- `ELEVATED_RESEARCH`只在`BASELINE`全部盈利门禁通过后运行。

**Checkpoint D**

- 同一确认集不能反复选择成员、阈值或风险档。
- 提高风险后必须同时报告收益、回撤、尾损和资金利用率。
- `ABSOLUTE_CAP`无法被自动发布。

### Phase 5: 生产同源账户回放

- 从脱敏决策包恢复同一决策状态并调用生产纯内核。
- 纳入T+1、涨跌停、滑点、费用、未完成订单资金占用、跳空和跟踪退出。
- 逐日复算现金、持仓、费用和权益；与策略基线做配对比较。
- 191日历史仅作为已查看回归集，不作为最终未见验证。

**Checkpoint E**

- 同一决策包的线上纯内核和回放动作、价格、数量及拒绝原因一致。
- 10万元账户账本按分对平。
- 2倍滑点和执行延迟结果完整披露，不挑最好情景。

### Phase 6: 发布与运行验收

- 运行全量测试、Harness、离线Bakeoff和选择性发布。
- 未通过时记录阻断原因，不覆盖生产清单。
- 通过时先部署量化服务和主FC，再用测试账号做有副作用闭环。
- 线上生产个人账号只做只读版本、模型状态和账本核验。
- 冻结版本进入至少60交易日前向记录；该窗口只证明运行，不自动证明长期盈利。

### Phase 7: Alpha158 联合排序与人工建议

- 将主板 Alpha158 训练为独立、可版本化的连续信号，不授予交易决策权限。
- 用扩展时序样本外分数选择融合权重，缺失或失效时严格退回 V3。
- 联合分只改变同层机会排序，不覆盖 V3 价格、成交、尾损和账户约束。
- 将最终结果收敛为唯一人工操作建议，用户确认与真实成交继续分离。
- 使用同一 10 万元账户比较 V3 与联合模型，5bps、10bps 均未改善时不发布。

**Checkpoint F**

- Alpha158 输入、输出、模型和联合排序合同均有版本与时点校验。
- 禁用 Alpha158 后，候选顺序与现役 V3 完全一致。
- 联合模型必须提高费后账户收益且保持净 R 下界为正。
- 系统不包含券商自动报单路径，真实成交仍由用户录入。

## Parallelization

可并行：

- ADR/文档与合成测试夹具。
- JS特征编码器和Python金样校验，但必须先冻结JSON合同。
- 风险档报告与账户账本审计，但必须先冻结风险合同。

必须串行：

- 特征合同 → 服务端请求 → Python推理 → 模型注册表。
- 标签合同 → 时间分区 → 模型训练 → 最终确认。
- `BASELINE`门禁 → `ELEVATED_RESEARCH`评估 → 发布裁决。
- 量化部署 → 主FC部署 → 测试账号验收。

## Verification Matrix

| 层级 | 验证 |
|---|---|
| 纯函数 | 合同哈希、缺失掩码、时间分区、风险档上限 |
| 跨语言 | JS/Python特征名称、顺序、数值和版本完全一致 |
| 模型 | 校准、直接/分解消融、Q10覆盖、OOD、推理延迟 |
| 决策 | 相同决策包产出相同动作、价格、数量和阻断原因 |
| 账户 | 现金、持仓、费用、应收、未完成订单和权益逐日对平 |
| 系统 | lifecycle、execution、portfolio、CI Harness |
| 发布 | 兼容性、原子Manifest、失败关闭、版本回滚 |
| 线上 | 测试账号副作用验收；生产账号只读 |

## Deployment Order

1. 代码与测试全部通过，提交并推送。
2. 训练挑战者，不覆盖生产Manifest。
3. 运行候选选择和一次性最终确认。
4. 未通过则停止部署模型；保持失败关闭。
5. 通过则部署量化FC。
6. 构建、打包并加载`.env`后部署主FC。
7. 若触及前端，同一版本部署Vercel和FC。
8. HTTP冒烟、测试账号闭环、生产只读核验。

## Risks and Mitigations

| 风险 | 影响 | 缓解 |
|---|---|---|
| 历史完整事件不足 | 成交头无法训练 | 保留采集和拒绝事件；样本不足即不发布 |
| 价格合同迁移使旧模型不可用 | 暂停新增风险 | 先完成代码兼容与失败关闭；不强制恢复旧模型 |
| 最终确认集被多次查看 | 收益高估 | 写入不可变试验登记；失败后必须使用新时间数据 |
| 高风险档扩大亏损 | 回撤上升 | `BASELINE`先过门禁；研究档独立报告；绝对档需再批准 |
| 回放缺原始决策包 | 无法证明同源 | 新事件开始完整归档；旧数据只作有限回归 |
| 训练/推理版本漂移 | 线上错误评分 | 合同哈希、模型包哈希、跨语言金样和注册表拒绝加载 |
| 工作区存在他人改动 | 合并污染 | 逐文件读取、仅提交任务文件、不清理或回滚他人内容 |

## Non-Goals

- 不承诺固定年化收益或每月盈利。
- 不提高杠杆，不接券商自动报单。
- 不把ETF黄金收益或未经核验的公告因子混入个股模型收益。
- 不在本阶段重写36维OHLCV模型。
- 不为获得更多交易而降低正期望和发布门槛。

## Approval Gate

本计划和配套任务清单需用户审阅。批准后从Phase 1按任务顺序实施；每个Checkpoint通过后继续下一阶段。生产模型与风险档切换仍受最终发布门禁约束。
