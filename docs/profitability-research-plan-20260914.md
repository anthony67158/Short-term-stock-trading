# 10万元账户盈利路线调研与验证方案

> 状态：Draft / proposed，未经用户批准，不代表已实现或已盈利。
> 版本：research-design.v1；日期：2026-09-14；决策者：用户。
> 事实基线：代码 `b603a159c8fb001a003b876e9689cd6bd5dd82cb`、191日回放脚本与结果、正式训练 Run `34770187790`。
> 本轮范围：只读研究代码、公开资料检索、新增研究文档。没有修改策略、训练模型或部署生产。

## 1. 执行摘要

**有值得验证的盈利路线，但现有证据不能保证任何新方案盈利。建议改变收益来源与交易周期，而不是继续在同一批数据上调高胜率或降低门槛。**

推荐顺序：

1. **先建立可信的收益验证基线。** 纠正旧回放与生产仲裁、证券交易规则之间的差异，停止把现有数字称为完整生产系统的一年收益。
2. **第一优先：境内上市ETF的低换手、跨资产趋势轮动。** 用数周至数月的价格延续获取收益，尽量降低个股跳空、最低佣金及频繁交易的影响；先做简单规则对照，再检验模型是否增加价值。
3. **第二优先：业绩公告后的信息消化波段。** 用当时可获得的业绩意外信息召回个股，交易后续消化过程，不把上涨本身或LLM新闻情绪当作独立优势。
4. **短周期反转只作小范围研究对照。** 它可能利用流动性冲击，但交易成本和T+1约束更苛刻，不先承担主账户盈利任务。

各路线先使用独立的10万元虚拟账户。只有单独通过验证的路线才研究组合配置；不得将几条负期望路线混合后宣称分散化能够创造盈利。

**现在不能给出“10万元每年能赚多少”的可信点估计。** 下一阶段应交付逐笔成交、逐日权益、跨年份费后收益分布、最差年份和回撤，而不是先承诺年化收益。

## 2. 问题定义

核心问题：在10万元、不加杠杆、仅买入持有或减仓、实际权限与成交成本约束下，能否找到跨多个市场阶段仍具有费后优势、并能由当前工作台可靠执行的策略？

当前差距不是“模型不肯买”，而是“对能成交的交易，尚没有可重复验证的费后优势”。强制增加交易只会放大这一缺口。

关键变量：

- 优势持续时间是否长于观察、人工执行、T+1及成本回收所需时间。
- 信息是否真的在当时可获得，而不是事后修订财务数据、补齐标签或未来成分股。
- 盈利来自风险暴露、择时、选股还是偶然几笔交易。
- 策略的优势能否在账户实际权限、份额约束及成本压力下保留。
- 用户是否接受持有周期延长至数周或数月，以及可能连续数月亏损。

## 3. 目标与非目标

### 目标

- 找到有合理机制和可否证证据的候选路线。
- 在完整资金账本上证明费后收益，不以分类准确率提升代替盈利。
- 比较同样资金、同样可交易标的、同样风险约束下的简单基线。
- 系统给出明确的当前动作、数量、依据和失效条件，用户只核对并记录实际成交。

### 非目标

- 不承诺每月、每年或所有行情都赚钱；不靠提高风险把回测收益做正。
- 不做融资融券、期货、期权、做市或超低延迟套利。
- 不以网格加仓、摊薄成本或只统计已平仓利润掩盖浮亏。
- 不恢复已废止的提前成交标签、统一盈亏比门槛或固定第5日退出主链。
- 本轮不实现ETF接口、行情回填、策略代码、重训及上线。

## 4. 核心约束与不变量

- 保留真实账户、持仓、成交、T+1批次、执行计划与成交归因。
- 唯一生产决策入口仍是模块化决策引擎及统一仲裁；新策略不得另建旁路直接买入。
- 新增风险必须有费用和滑点后的正期望证据，并满足现金、可卖数量和开放风险限制。趋势为正不是正期望的充分证明。
- LLM只解释，不能生成或覆盖价格、数量、账户风险与动作。
- 候选模型未过正式门禁不能覆盖生产。ETF若需不同持仓期限和标签合同，必须先单独设计并批准，不能拿股票短线模型直接评分或绕过现有门禁。
- 本轮仅有研究授权。真实资本分配、风险容忍度、付费数据购买及交易自动化均需用户另行确认。
- 10万元实验资本不等于没有历史交易权限，也不等于自动拥有科创板、创业板、北交所权限；必须显式配置，未知则排除相应直接个股交易。

## 6. 外部调研与证据边界

### 6.1 趋势延续有研究依据，但不能照搬海外多空收益

Moskowitz、Ooi、Pedersen的《Time Series Momentum》（2012）研究58个流动性较好的期货及远期品种，发现约1至12个月尺度上的趋势延续[1]。这支持“用较长周期研究趋势”而非“10分钟形态一定能预测后续数日”。

原研究涉及股票指数、债券、商品、外汇及多空实施。中国境内上市ETF的仅多头轮动是**改造假设**：在某资产下跌时只能减仓、转向其他合格资产或现金，并不具备原论文的做空收益来源。震荡、V形反转和各类资产同时下跌均可能使其亏损。

更贴近个人账户的Faber《A Quantitative Approach to Tactical Asset Allocation》基础策略采用月末10月均线与仅多头/现金配置[9]。但其原规则不计税费、佣金与滑点，并按信号当日收盘成交；本项目只能把它作为少参数机制基线，必须改成信号可知后的成交并重新计费。**月度策略是来源对应的基线，周度60/120日轮动是另一个需要独立验证的快周期改造，不混称为论文原策略。**

### 6.2 ETF降低部分实施负担，不等于没有成本与风险

上交所说明：普通股票ETF为T+1，部分债券、黄金、跨境及货币ETF可当日回转；普通ETF买卖单位为100份[2]。必须按具体基金产品核实，不能把“黄金相关股票ETF”当成实物黄金ETF。

ETF二级市场交易免印花税；管理、托管等费用在净值中计提[4]。实际佣金及最低收费取券商合同，价差、溢折价、跟踪误差、跨境时差仍存在。使用真实基金价格和分红回测时，不应再重复扣除已体现在净值中的管理费；使用指数代理研究时则不能忽略可投资产品费用。

### 6.3 事件与反转是候选机制，不是现成收益率

Shu与Tan（2022）使用中国A股2000至2020年半年报与年报观测，报告业绩披露后的价格漂移及其与意见分歧的关系[10]。这支持检验“新信息被分阶段消化”，但本轮没有完整核验其组合构造和费用表，不能称作仅多头费后盈利证据。

反方也必须保留：Chui、Subrahmanyam与Titman（2022）在同公司A/B股比较中，发现A股月度反转，并称反转主要来自上涨后回落，而非下跌后反弹；该样本中动量和业绩漂移主要出现在B股[11]。这既限制“超跌买入”的论证，也提示公告策略必须分样本验证。

公告当日跳涨、涨停无法买入、多空组合、历史交易制度及昂贵换手，都可能让论文异常收益不能转化为个人账户收益。

详细论文、样本范围及读取边界见配套[一手来源笔记](./profitability-strategy-primary-sources-20260914.md)。本方案不引用论文年化收益作为账户收益预测。

### 6.4 反复改到盈利必须控制多重试验

Bailey与López de Prado的Deflated Sharpe Ratio研究指出，多重试验、选择性报告和非正态收益会夸大表现，反复使用留出集也不能自动消除该问题[5]。

因此“每次失败就换模型、继续试直到为正”不是验收方法。所有成功与失败试验、参数、数据版本和选择过程都要保留；以日期或事件簇处理依赖性，不能把同股三条路径当成三个独立赚钱证据。

## 7. 备选方案与决策

| 路线 | 收益机制与最强支持 | 最强反方与失效条件 | 数据与工程代价 | 推荐 |
|---|---|---|---|---|
| ETF低换手跨资产趋势 | 较长趋势延续；分散单一公司风险；降低频繁换手；通常不需要新增个股权限 | 仅多头不同于期货多空；震荡反复止损；股债金可能同跌；长期落后持有基线 | 中：需多年真实ETF数据、分红、规则、溢价和资产类别合同 | 第一优先验证 |
| 业绩公告后的波段 | 外生的新业绩信息可能逐步定价，更接近前瞻信息需求 | 市场可能已定价；可交易时优势已消失；财报修订与发布时间容易泄露未来；季度样本有限 | 高：带发布时间和历史版本的公告、预期基准、事件归因 | 第二优先 |
| 流动性冲击后的反转 | 可检验短期过度反应，可能与趋势互补 | 补偿的是流动性和尾部风险；单边下跌中越跌越买易扩大损失；T+1与费用侵蚀 | 中高：点时股票池、成交能力、时段价格和负面事件排除 | 小范围对照，不先上线 |
| 继续调现有10分钟复核模型 | 数据和基础设施可复用，修正后信息特征可能改善 | 当前未有可发布优势；同一区间已大量试验 | 中，但重复试验成本累积 | 冻结为比较基线，先查特征和链路 |
| 不交易/简单分散持有 | 成本低，是必须击败的基线 | 现金有机会成本；持有组合承受市场回撤 | 低 | 必须保留，不能人为选弱基准 |

**暂定裁决：优先ETF，不是因为已有中国实盘盈利证明，而是因为它最适合低成本验证，并减少当前策略面对的单股噪声、最低收费和短时信号执行问题。**

反方改变了推荐范围：不承诺“全行情盈利”，不直接移植海外多空收益，不立即给ETF分配真实资金，也不排除简单持有最终优于轮动。如果ETF在匹配风险的基线上没有优势，则不为了保留复杂产品而上线。

## 8. 推荐路线的可检验规则

以下数字是**预注册研究起点，不是经优化的最优参数或投资建议**。在用户批准实验并冻结版本后才能测试；失败后不得悄悄更改同一版本。

### 8.1 第一阶段：ETF趋势与现金的独立虚拟账户

1. **范围：** 先覆盖A股宽基/红利、黄金、债券；境内上市跨境ETF仅在有点时净值/溢价及交易时区数据时加入。同指数重复产品去重，不能通过同时买很多同方向行业ETF伪装分散。
2. **可用池：** 当时已上市且有至少252个交易日数据；按上一交易日可知的近20日成交额与流动性规则选产品。门槛和代表基金选择在M0冻结，保留后续清盘和退市产品，禁止事后挑存活赢家。
3. **信号：** 先固定月末10月均线的趋势/现金方案作为来源对应基线。另登记一个快周期挑战者：每周最后交易日收盘后，计算60日与120日总回报等权均值，以正趋势入围并排序；不是测试完再选择窗口。趋势条件仅属于该策略，不是市场弱时对其他合法策略的一票否决。
4. **收益检验：** 比较“简单持有”“月度趋势”“周度轮动”“通过开发验证后的最佳规则加费后价值筛选”，最多四个登记版本，全部保留结果。规则组只是离线对照，不获生产买入豁免。生产候选还须有使用更早数据建立、经校准和独立验证的费后期望估计；最后一组的规则选择只发生在开发段，不使用最终测试收益。
5. **持仓：** 最多3只，研究初始单只上限20%，其余保留现金；仓位还受跳空压力、单笔及总开放风险约束。禁止为抬收益而默认使用杠杆或把剩余资金自动投向债券。
6. **成交：** 收盘形成信号，下一交易日预定可成交时段执行。不能用收盘后信息按同日收盘价成交。定手数后按真实成本再核验净期望。
7. **退出：** 按所属版本月度或周度检查趋势失效，轮动版另比较更好的合法配置；日内硬风险例外仍即时处理。持仓允许数周至数月，不套用股票5日标签或统一0.5R跟踪幅度。资产专属退出规则须在实验前冻结并统一训练/回放/执行。
8. **交易减少规则：** 新旧配置的预期增益不足以覆盖切换成本时不换；没有合格配置时保持现金。跨境溢价或参考净值不可可靠获得时跳过，不猜净值。

原股票`/predict`的36维接口不变。未来ETF接入需新增可交易品种元数据与经批准的任务合同，最终仍通过唯一仲裁器、账本和风控。

### 8.2 第二阶段：只验证一种公告事件

优先“业绩预告/快报的盈利超预期”，暂不混入供应链传闻、机构调研热度、回购意向及LLM情绪评分，避免样本口径混杂。

- **信息：** 保存交易所/巨潮公告原文、首次发布时间、首次采集时间与每次更正版本；先检查更早预告，避免重复事件。
- **意外程度：** 有历史一致预期快照才计算分析师预期差；没有就用只在更早数据上拟合的季节性基线，明确叫“相对统计基线的意外”，不能把同比增长等同于市场超预期。
- **质量：** 营收、扣非利润、现金流和一次性损益均只使用当时已公布信息，禁止把以后年报补到事件当天。
- **交易：** 只考虑已经确认权限的个股，在公告可知后的首个预定交易时段评估；涨停排队无法成交必须记未成交。10分钟观察是否增加价值由对照验证，不视为优势来源。
- **周期：** 研究信息消化过程，可观察5/10/20日结果，但必须在训练/开发段选定唯一主期限及退出规则，再锁定样本外测试。多个期限都计入试验次数，不按每笔事后最佳退出。
- **判断：** 先证实简单事件分组的费后优势，再考虑模型排序。LLM只读公告用于解释，不负责认定超预期或下单。

如果买入后的收益不再为正，说明优势集中在无法捕获的跳涨或已被交易者吸收，该事件路线停止。

### 8.3 第三路线：反转的研究边界

只测试流动性足够、无已知重大负面公告的标的或宽基ETF，观察偏离后的恢复；禁止越跌越加、无限网格和一律抄底。它必须独立通过费后、T+1及尾部压力验证才能申请进入组合。

ETF趋势未完成前，不扩大到全市场高频反转，也不以T+0权限本身作为收益依据。

## 9. 优先级与里程碑

| 优先级 | 里程碑与可验收状态 | 范围/证据 | 退出条件与停止动作 |
|---|---|---|---|
| P0 | M0：收益数字可信、规则冻结 | 固定代码/数据哈希、实际账户权限、逐事件仲裁、证券类别撮合、48日热身独立披露、全部试验登记 | 任一非法买单、资金账本不守恒、时间穿越或生产合同分叉未解决，不进入策略收益排名 |
| P1 | M1：ETF路线值得或不值得继续 | 目标2016年至今的可投资产品日线/分红/规则；上市前指数只作机制研究；至少覆盖上涨、下跌、震荡与快速反转 | 三个基线在同一账户约束下比较；主结果及成本压力均不过门槛则停止，不增加复杂模型挽救 |
| P1 | M2：公告路线存在或不存在可交易的增量收益 | 带历史版本公告、至少多个完整财报年度、匹配行业/规模对照、公告可知后的实际买点 | 只有事件后可成交收益有优势才继续；时间戳或历史预期不足时该路线不可验收 |
| P2 | M3：研究结果可由工作台复现 | 离线生产同源回放、测试账号闭环、冻结策略后的前向纸面账本 | 数据/动作/金额一致、正式门禁通过、用户批准后才允许生产切换 |

研究投入上限：首轮最多3类策略、每类最多4个预注册版本，共不超过12次主试验；这些次数只是防止无限搜索的预算，不是统计显著性的保证。邻近参数诊断也须记录，若据此重新选择，视为新一轮研究，旧测试段退为开发数据。

不做工期承诺：ETF多年数据可能较易取得，公告点时数据和真实成交细节可能需要付费来源。先完成数据可得性检查再估算，未经确认不购买。

## 10. 验收与指标

### 10.1 交易与时间正确性

- 同一输入直接运行生产特征、统一仲裁与执行合同，输出动作、数量、拒绝原因和成交账本；不得在临时脚本重新写一套近似规则。
- 明确K线时间戳是开始还是结束、何时整根数据可知。5分钟K线只能提供5分钟精度的路径，不得声称具有真实1分钟或逐笔精度。
- 当根的最高/最低价不可在成交前知晓；同根止损/止盈顺序不明时使用事先约定的保守规则并报告歧义比例。
- 证券权限、最小股数、价格档位、当时ST状态、涨跌停、停牌、T+1、现金冻结、撤单释放均可追溯。
- 市场行情缺失不能零收益“成功通过”，也不能仅保留最终可成交和可结算样本；区分信号、未成交、未成熟、缺数据和已实现收益。
- 分红、除权、税费、基金份额变化及现金利息一致入账。不能将复权信号价格直接作为真实成交价。

### 10.2 盈利证据

以下是拟议的研究推进门槛，不代替现有生产发布规范：

| 项目 | 拟议门槛/报告口径 |
|---|---|
| 绝对收益 | 完整样本外账户费后累计收益为正，包含全部空仓和持仓日 |
| 可比基准 | 同风险约束的简单持有/静态分散、现金均报告；不能仅击败旧亏损模型 |
| 真正增量 | 相对预先指定的风险匹配基线，按日期块bootstrap估计平均超额收益95%下界为正；样本不足则标“未证实”，不擅自放宽 |
| 稳健性 | 至少3段预先确定的滚动样本外区间，公布每段收益；不能只依赖一个行情或少数股票 |
| 成本压力 | 佣金按合同，滑点按基础与2倍压力；压力情况下费后总收益仍为正。用真实溢价而不是把跨境ETF一律按净值成交 |
| 回撤 | 暂以账户最大回撤10%为研究筛选上限，实际风险容忍度待用户确认；止损不能保证回撤不穿透 |
| 样本数 | 报告独立日期/事件簇有效数量和区间宽度；不把18笔或十几万重叠标签当稳定证据 |
| 多重试验 | 记录全部版本并计算适当的选择偏差诊断；不能把三个种子当三次独立策略验证 |
| 前向验证 | 冻结后至少60个交易日纸面运行作为流程验收；长周期路线还需足够成熟持仓样本，60日不是盈利证明 |

既有191日数据已影响过策略选择，只用作开发与回归；新收集的更早历史可作额外检验，但不能替代冻结规则后的未来数据。

必须区分两种“下界”：**平均收益的统计置信下界**与**单笔收益Q10分位数**。前者用于优势可信度，后者用于尾部风险；不能要求每笔Q10为正，也不能把负Q10自动解释为无正期望。

收益报告至少包括：期末权益、费后年化及累计收益、各年份和滚动12个月分布、最差年份、最大回撤/水下期、平均仓位、换手、费用、无法成交比例、相对基准的超额收益。研究和服务费用另列，给出扣除后的账户经济收益，不能在10万元账户上忽略这部分成本。

## 11. 风险与停止条件

- **ETF优势不存在：** 若与风险匹配的静态组合相比没有稳定优势，选择简单基线或不部署择时，不靠增加参数补救。
- **行情适用性变化：** 股票、黄金、债券同时下跌或震荡会亏损；不承诺用自动识别行情解决所有亏损期。
- **事件优势不可成交：** 涨停或发布延迟耗尽收益则停止该类事件，不用理论开盘价补成交。
- **过拟合：** 锁定测试、保留失败记录、按日期/事件簇估计不确定性；任何测试后调整都必须重新获得独立证据。
- **训练/线上不一致：** 同源合同或数据时钟未对齐时禁止发布，即使回测为正。
- **样本不够：** 延长观察或停止投资性结论，不能为增加样本而降低合法性、成本或正期望门槛。
- **发布与回滚：** 保持现有失败关闭；未来仅在测试账号和全部门禁通过后经批准切换，保留版本级回滚，不让新旧引擎同时给生产账户决策。
