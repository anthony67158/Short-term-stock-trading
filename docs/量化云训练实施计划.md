# 量化云训练实施计划

> 前置规格：`docs/量化云训练与生产隔离规格.md`
> 当前状态：阶段 0 完成，阶段 1 待执行。

## 架构决策

1. 生产和实验使用独立 OSS Bucket 与独立 RAM 身份。
2. 生产 FC、`QUANT_URL`、`QUANT_KEY` 和 `quantmodel/` 在影子验证前不修改。
3. DSW 用于交互开发，DLC 用于可重复训练，EAS 只在确有推理性能需求后启用。
4. LightGBM 和特征构建优先 CPU；TCN 等时序模型训练才使用 GPU。
5. 自动训练只能生成 challenger；生产晋级必须使用独立人工身份。

- 结论：Transformer 的分类指标最佳，GRU 的概率损失最低；当前选 Transformer 作为影子候选，不自动晋级生产。
- 扩充数据 v3 对拍：TCN/GRU/Transformer 的 Balanced Accuracy 分别为 0.5882/0.5963/0.5930，均未达到 0.60 影子门槛。
- 最终选择：继续使用 v2 Transformer 作为影子候选；v3 只保留为“更多数据不等于更强模型”的可追溯失败实验。
