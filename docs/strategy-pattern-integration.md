# 五策略形态接入

## 目标

将平台整理突破、缩量回踩、量价齐升、长下影反击和低波动趋势拆为独立的
确定性产品工具：扩大召回、提供价格锚点、收紧触价确认并展示可核验依据。
形态不得直接生成买卖动作，也不得覆盖费后动作价值、账户风险、T+1、现金
或仓位约束。

参考项目为 `shy3130/tick-stock-panel`。本项目只参考策略语义，并按现有
数据合同重新实现，没有复制其固定止损、固定持有期或交易动作。

## 运行链路

```text
已校验全市场日线归档
  -> 前一交易日全市场形态快照
  -> 原四路召回 + 最多16只形态增量候选
  -> 60根日线重算当前形态
  -> 现价/回踩/突破三路径（可使用形态锚点）
  -> 现役生产动作价值模型重新评分
  -> 账户风控与触价复核
  -> 形态专属条件只收紧确认
```

形态快照位于
`opportunitymodel/pattern-data/v1/`，使用不可变压缩对象和带 SHA-256
的活动清单。快照缺失、过期或覆盖不足时，扫描保持原四路召回，不使用旧值
冒充当前形态。

线上拆分为六个能力开关：

| 开关 | 当前状态 | 作用 |
|---|---|---|
| `STRATEGY_PATTERN_RECALL` | `ACTIVE` | 在原深查池外追加最多16只形态候选 |
| `STRATEGY_PATTERN_PRICE_ANCHORS` | `ACTIVE` | 使用平台上沿、MA20或下影低点生成可达路径 |
| `STRATEGY_PATTERN_CONFIRMATION` | `ACTIVE` | 触价后观察满60秒并校验形态专属条件 |
| `STRATEGY_PATTERN_DISPLAY` | `ACTIVE` | 展示形态数值与触价后核对项 |
| `STRATEGY_PATTERN_PLAYBOOK_BLEND` | `RESEARCH` | 禁止形态分改变六打法权重 |
| `STRATEGY_PATTERN_MODEL_FEATURES` | `RESEARCH` | 向生产模型输入的16个形态字段固定为0 |

旧 `STRATEGY_PATTERN_POLICY` 仅保留兼容读取并固定为 `RESEARCH`。形态新增
候选以现役模型已有的 `EXPLORATION` 召回语义评分，禁止伪装成动量或资金
召回样本。

## 五类形态

| 形态 | 原始指标 | 主要打法 | 主要路径 |
|---|---|---|---|
| 平台整理突破 | 10日平台振幅、距平台上沿、量能比 | 主升突破 | 突破、现价 |
| 缩量回踩 | MA20/MA60距离、缩量、20日动量 | 核心回踩、区间低吸 | 回踩 |
| 量价齐升 | MA20上穿、量能比、阳线确认 | 主升突破、资金潜伏 | 现价、突破 |
| 长下影反击 | 下影比例、5日跌幅、收盘位置、量能 | 恐慌修复 | 现价、回踩 |
| 低波动趋势 | 20日动量、年化波动、MA20位置 | 核心回踩、区间低吸 | 回踩、突破 |

每类形态输出 `0-100` 连续强度分。70分只表示形态证据成立，不代表允许
交易。生产打法层不读取形态分；历史研究仍保留最多12%-20%的形态权重实验，
但不能进入线上动作。

触价确认采用服务端固定合同，客户端不能自定义。形态条件必须先观察满60秒，
并按路径检查站稳触发位、VWAP、低点抬高、回升幅度和量能延续等公开行情
原语。该合同只能把通用确认从“通过”降为“等待”，不能把失败动作提升为通过。

## 特征合同

`opportunity-score-feature.v6` 在 V5 的 120 维基础上新增 16 维：

- 10 个可复算原始指标；
- 5 个形态连续强度分；
- 1 个历史覆盖率。

盘中量能使用决策时点报价的量比；收盘量能使用当日成交量除以前五日均量。
历史回放只使用信号日前已经完成的日线生成全市场召回快照，再使用信号时点
行情重算深查候选，禁止使用未来收盘数据。

## 发布门禁

- 历史形态覆盖率至少 95%；
- 新合同与旧冠军使用同一批样本和同一时间切分比较；
- 训练、校准和最终留出严格分离；概率校准与混合权重选择不得使用最终留出；
- 必须提供三个滚动样本外窗口通过的证明，不能用末段单次评估替代；
- 跨特征合同只能整包晋级，禁止混合 V5/V6 模型头；
- Top5 费后净R下界必须为正；
- 最大回撤、命中率、覆盖率、校准误差和推理耗时必须通过现有选择性发布门禁；
- 任何门禁失败均保持当前生产清单。
