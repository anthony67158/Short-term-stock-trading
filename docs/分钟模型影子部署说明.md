# 分钟模型影子部署说明

## 当前结论

- 生产 `/predict`、`QUANT_URL`、现有 AI 建议和预警保持不变。
- 影子候选为 `run-20260811-minute5m-v2` 的 Transformer。
- v3 虽将数据覆盖率提升到 99.80%，但留出指标下降，已拒绝晋级。
- EAS 服务 `stock_quant_lab_shadow` 已部署，默认停止，由前端模型开关按需启停。
- 影子服务只提供 `/predict-v2`，输出三类概率和派生展望，不返回买卖动作。

## 服务边界

影子服务必须使用独立名称、地址和 API Key：

```text
服务名：stock_quant_lab_shadow
公网网关：https://1730034925594178.cn-hangzhou.pai-eas.aliyuncs.com/api/predict/stock_quant_lab_shadow
接口：POST /predict-v2
鉴权：Authorization + X-Shadow-Key
模型挂载：/mnt/data/runs/run-20260811-minute5m-v2/intraday/transformer.pt
日志：实验 OSS shadow/predictions/<date>/
```

不得配置为生产 `QUANT_URL`，不得写入生产 `quantmodel/`。

## 容器

构建文件：

```text
qlib-service/Dockerfile.shadow
qlib-service/requirements.shadow.txt
```

构建上下文必须是 `qlib-service/`。候选模型不写入镜像，部署时从实验 OSS 只读挂载：

```text
datasets/runs/run-20260811-minute5m-v2/intraday/transformer.pt
```

模型 SHA-256：

```text
2e9ed5226a4414eca028ed5d48425977728979b7626bfb8fdda37eca1840552f
```

## 环境变量

模板为 `qlib-service/cloud/env.shadow.example`。真实 API Key 和 OSS 临时凭据只通过阿里云服务配置注入，不能写入镜像、代码或聊天。

## 上线顺序

1. 前端选择 V2，并开启在线服务。
2. FC 校验账号确实选择 V2 后，拉取最近完整 5 分钟序列。
3. 东财分钟镜像不可用时，回退腾讯真实 5 分钟行情。
4. FC 携带双层鉴权调用 `/predict-v2`。
5. EAS 将非动作型预测写入实验 OSS。
6. 下一交易日结束后，定时任务生成按信号日正确率。
7. 连续观察 14 至 28 天后，才能申请人工灰度。

## 验收

- 未携带 `X-Shadow-Key` 返回 401。
- 非 15:00 日终数据返回 422。
- 模型文件 SHA-256 不匹配时返回 503。
- OSS 写入失败时不返回未记录的预测。
- 影子响应和日志中均无 `action`、`position`、`decision`。
