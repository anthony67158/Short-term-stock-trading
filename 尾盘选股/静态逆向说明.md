# 尾盘拾金 TN6 静态逆向说明

## 结论

`尾盘公式一键导入.tn6` 已完整恢复出三个公式正文：

- `尾盘拾金主图.txt`
- `尾盘拾金副图.txt`
- `尾盘拾金选股.txt`

三段源码长度分别为 1328、1861、1425 字节，合计 4614 字节；解密数据区
总长 4616 字节，剩余 2 字节均为零对齐。源码按 GB18030 解码，中文变量名
和提示文字均可完整还原。

## 解密算法

通达信金融终端 3.61 的 `-[TdxCore ImportGsByTN6File:]` 中硬编码了容器密钥：

```text
DAMI@TCALC1.0_EXPORT^_^
```

算法为 Blowfish ECB，23 字节密钥，无填充。通达信实现按小端 `uint32`
读取每个 8 字节分组，因此使用标准 Blowfish 库时需：

1. 每 4 字节反序。
2. 执行标准 Blowfish ECB 解密。
3. 每 4 字节再次反序。

该转换分别作用于 48 字节文件头、公式索引区和公式正文区。

## 实际选股条件

最终选股表达式只使用以下条件：

```text
AX_1 AND AB1 AND AB2 AND AB4 AND AB5 AND HSL
AND AB6 AND AB8 AND AB9 AND AB10 AND AB7
AND AB12 AND AB32 AND AB34
```

白话含义：

| 条件 | 实际含义 |
| --- | --- |
| `AX_1` | 排除名称含 ST、`*ST`，并排除 68/8/4/9 开头代码 |
| `AB1` | 昨收低于前日收盘 |
| `AB2` | 当日收阳 |
| `AB4` | 上影长度大于开盘至最低价距离的 1.5 倍 |
| `AB5` | 当日最高价相对开盘价上涨 1%-9% |
| `HSL` | 当日换手率大于 5% |
| `AB6` | 当日最高价低于两日前最高价的 99.5% |
| `AB7` | 当日最低价低于两日前最低价的 99.5% |
| `AB8` | 昨日相对前日收盘下跌超过约 3.29% |
| `AB9` | 当日成交量不低于近 30 日最高量的 20% |
| `AB10` | 当日收盘涨幅超过 2.4% |
| `AB12` | 上影不超过收盘价 6%，且最高价不显著越过昨日高点 |
| `AB32` | 当日量不超过前 15 日最低单日量的 4 倍 |
| `AB34` | 三日前 K 线实体幅度小于 4% |

`AB8` 的精确跌幅为：

```text
REF(CLOSE,2) / REF(CLOSE,1) > 1.034
```

等价于昨日收盘低于前日收盘约 3.29% 以上，而不是简单的 3.4%。

## 与使用说明的边界

源码本身没有实现以下规则：

- `14:50-15:00` 时间限制。
- 大盘 5/10/20 日均线环境判断。
- 大盘跌破 60 日均线时停用。
- 分时价格是否长期位于均价线上方。
- 尾盘是否出现放量跳水或直线拉升。
- 20 日涨幅超过 35% 的高位过滤。
- 日成交额低于 5000 万元的过滤。
- 次日减半、7%-8% 清仓、最多持有 3 日。

这些都是公式外部的运行时机、人工过滤或退出纪律。系统实现时必须将它们作为
独立确定性闸门，不应宣称它们来自原始选股公式。

## 副图审计

副图把信号日收盘价作为“买入”，固定设置：

- 止盈：买入价 `+1%`
- 止损：买入价 `-3%`

副图的：

```text
涨幅 := (次日收盘 / 买入 - 1) * 155
```

乘数 `155` 并不是标准百分比，应视为展示逻辑或原作者自定义缩放，不能用于
真实收益统计。“成绩”才按次日最高价相对买入价计算百分比：

```text
成绩 := (次日最高价 / 买入 - 1) * 100
```

这意味着宣传中的“胜率”很可能采用“次日盘中最高价曾达到 +1%”作为成功，
并不等于可成交、扣费后盈利或次日收盘盈利。正式接入前必须按项目已有手续费、
滑点和 T+1 引擎重新回测。
